# 托盘菜单


## 入口

在 Windows 通知区域右键 MemeMomo 图标，打开应用自定义的托盘菜单。图标可能收纳在任务栏的“显示隐藏的图标”区域中。右键[主窗口贴边方块](/#/docs/功能指南/主窗口贴边方块)也会打开同一菜单。

默认左键双击托盘图标直接恢复主窗口；若用户改成单击显示，则单击即可。左键恢复和右键打开菜单是两种操作。

## 菜单功能

| 条目 | 作用 |
| --- | --- |
| 打开备忘录 | 显示或恢复完整主窗口，不直接新增记录。 |
| 新建备忘录 | 显示主窗口，尝试完成当前编辑，切到新建输入区并聚焦；输入内容后仍需提交。 |
| 窗口置顶 | 切换**主窗口**置顶，图钉状态反映是否已开启。 |
| 退出应用 | 结束应用及本次后台提醒运行，并关闭相关窗口。 |

托盘菜单的置顶固定作用于主窗口；全局 `Ctrl + Alt + T` 则依据最近激活的主窗口、便签或教程窗口选择目标。

## 菜单显示与收起

菜单出现在鼠标附近，靠近屏幕边缘时会调整方向或位置，尽量留在工作区内。它作为短暂浮层显示，不能缩放；执行菜单命令、点击外部或应用失活后会收起。

## 找回窗口与退出

主窗口的最小化、选择“最小化托盘”后的关闭，都只是隐藏主窗口。托盘还在时，快速添加与提醒仍可继续运行，已有独立便签也可能仍在桌面上。

需要明确停止运行时选择“退出应用”。再次使用需重新启动程序，已保存备忘录和提醒数据保留。新建草稿必须先提交，不能把退出当作新增操作。
