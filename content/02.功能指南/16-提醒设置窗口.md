# 提醒设置窗口


## 用途与入口

在[独立便签窗口](/#/docs/功能指南/独立便签窗口)标题栏点击时钟“设置提醒”，为当前备忘录安排一次提醒。主列表卡片没有直接的提醒按钮，需要先拖出便签。

它是单条记录的时间安排窗口，与应用全局设置面板分开。同一条记录已经打开提醒窗口时，再次打开会优先激活现有窗口。

## 界面布局

| 区域 | 功能 |
| --- | --- |
| 标题与备忘录标题 | 确认正在给哪条记录设置提醒。 |
| 当前提醒 | 有未来提醒时显示已保存的具体时间。 |
| 四个快捷按钮 | 1分钟后、10分钟后、半小时后、1小时后。 |
| 日期字段 | 打开[日期选择浮层](/#/docs/功能指南/日期选择浮层)。 |
| 时、分、秒 | 使用[时间滚轮](/#/docs/功能指南/时间滚轮面板)选择当天时间。 |
| 错误区 | 显示无效日期、时间过早或保存失败等提示。 |
| 底部按钮 | 取消提醒、取消、设置提醒；取消提醒只在打开时存在未来提醒的情况下显示。 |

窗口默认 360 × 400 逻辑单位，支持标题栏拖动，不能像主窗口那样自由缩放。

## 设置或修改提醒

1. 检查备忘录标题。
2. 选择日期和时、分、秒，或者直接点击一个快捷时间。
3. 点击“设置提醒”。时间通过检查并保存成功后，窗口关闭。
4. 回到便签后，时钟按钮突出显示，悬停可查看安排的时间。

没有未来提醒时，默认预选约当前时间的 10 分钟后；已有未来提醒时，载入该提醒时间。**预选或调整时间不会自动保存，必须点击“设置提醒”。**

快捷按钮从点击时的当前时间计算，不是给原选时间累加；跨午夜时会同步修改日期。所有时间按本机本地时间处理，精确到秒。提交时必须晚于当前时间约 1 秒，太近或已过去会提示“提醒时间需要晚于当前时间”。

一条备忘录只保存一个提醒时间，再次保存会替换原安排，不形成多个重复提醒。

## 三种取消方式的区别

| 操作 | 对已保存提醒的影响 |
| --- | --- |
| “取消提醒” | 清除该记录的提醒时间，保存后关闭窗口。 |
| “取消”或右上角关闭 | 放弃本次时间调整，保留原提醒。 |
| `Esc` | 在未保存忙碌时关闭面板，保留原提醒；日历浮层打开时先由浮层处理取消。 |

保存期间按钮进入忙碌状态，“设置提醒”显示“正在保存…”，不能重复提交。保存失败时错误会显示在窗口内，可根据原因处理后重试。

## 到期后的行为

应用运行或驻留托盘时检查提醒；完全退出后不再后台计时。下次启动会处理尚未触发而已经过期的提醒。每次到期处理后会清除该条安排，需要重复提醒时重新设置。

默认发送 Windows 系统通知；也可按全局偏好显示便签窗口或同时使用两种方式，见[到期提醒说明](/#/docs/功能指南/Windows系统提醒通知)。关闭便签本身不会取消提醒。
