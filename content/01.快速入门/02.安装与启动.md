# 安装与启动

适用版本：`v0.0.1`

MemeMomo 当前面向 Windows。获得应用有两种方式：直接运行发布版程序，或从源码启动。

## 方式一：从源码启动

**1. 安装 .NET 8 SDK**

开发和运行都需要 .NET 8 SDK，可以在 [dotnet.microsoft.com](https://dotnet.microsoft.com/download/dotnet/8.0) 下载。

**2. 获取源码**

克隆仓库到本地任意目录（或直接下载源码压缩包解压）。

**3. 启动**

在仓库根目录执行：

```powershell
dotnet run --project MemeMomo-wpf/MemeMomo.csproj
```

首次编译约需一分钟，之后应用会以紧凑的无边框窗口出现在屏幕中央。

## 方式二：运行发布版

如果拿到的是发布版程序（如 `MemeMomo-x.y.z-64.exe`），双击即可启动，无需安装 .NET SDK。发布版相关说明见下载页。

## 首次启动后

- 应用默认以紧凑的无边框窗口显示。
- 从「设置 → 教程」可以随时查看当前的快捷键和窗口操作。
- 把主窗口拖到屏幕边缘约 40 像素以内，它会自动收起成一个小方块；拖回屏幕内侧即可恢复。

> 提示：按下 `Ctrl + Alt + N` 可以随时唤起或恢复主窗口；`Ctrl + Alt + M` 把它最小化到托盘。
