# 全局快捷键

位置：**设置 → 快捷键**。应用运行时，全局快捷键可在其他应用获得焦点时使用。

| 功能 | 默认快捷键 | 作用与生效条件 |
| --- | --- | --- |
| 置顶 | `Ctrl + Alt + T` | 切换最近激活的主窗口、便签或教程窗口的置顶状态。 |
| 最小化 | `Ctrl + Alt + M` | 将主窗口隐藏到托盘。 |
| 显示软件 | `Ctrl + Alt + N` | 显示主窗口。 |
| 快速添加（剪贴板） | `Ctrl + Alt + C` | 收集剪贴板文本，需要开启“快速添加剪贴板内容”。 |
| 快速添加 | `Ctrl + Alt + Q` | 在鼠标位置打开空白便签，保存后新增。已有未保存草稿时将其移到鼠标处并激活，保留输入内容。 |
| 切换便签任务栏图标 | `Ctrl + Alt + B` | 切换最近激活便签的任务栏图标，需要开启“便签窗口任务栏图标”；无可用便签时无操作。 |

## 修改、清空和取消捕获

1. 点击某项右侧的快捷键按钮，进入“按下快捷键...”状态。
2. 按住 `Ctrl`、`Alt`、`Shift` 中至少一个修饰键，再按主键；释放主键时完成校验。
3. 合法组合会更新并自动保存；无效组合会通过气泡显示原因，有内部冲突时会标出占用该组合的功能，原值保留。

捕获期间按 **`Esc` 是清空这项快捷键**，清空后该全局快捷键停用；在快捷键按钮上**右键才是取消捕获并保留原值**。清空某个快捷键不会关闭对应功能，仍可从界面入口操作。

切换分类、离开设置或隐藏主窗口会结束尚未完成的捕获并保留原值，不会把离开页面当成清空。

## 可用组合与限制

- 主键可以是字母、数字、功能键、方向/导航键、支持的标点键或数字小键盘按键。
- 不能只设置单个按键，也不能只使用修饰键。
- 带 `Win` 的组合会被拒绝；`Alt + Tab`、`Alt + F4`、`Ctrl + Alt + Delete` 等系统保留组合会被拒绝。
- 当前校验还会限制包含 `Ctrl` 的常用编辑键组合，例如以 `C`、`V`、`X`、`S`、`N` 等为主键的组合，即使同时按了 `Alt` 或 `Shift` 也可能被拒绝。因此，内置默认值 `Ctrl + Alt + C`、`Ctrl + Alt + N` 在手动重新录入时可能无法通过当前校验；需要找回整套默认快捷键可使用“重置”。
- 不能与其他已启用功能的快捷键重复。重新开启此前关闭的功能后，应检查它的快捷键是否与现有配置冲突。
- 其他应用可能已经占用同一全局快捷键。当前设置页的内部校验不能保证 Windows 一定注册成功；保存后按键无反应时，可换一个组合，例如尚未被占用的 `Ctrl + Alt + F8`。

编辑器的 `Ctrl + Enter`、`Ctrl + B`、`Ctrl + I`、`Ctrl + K` 等是编辑器内操作，不属于这里的六组可配置全局快捷键；完整编辑用法可查看教程。
