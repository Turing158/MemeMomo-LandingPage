# 设置保存与自动记忆的状态

## 数据位置

正常运行时，配置位于当前 Windows 用户的：

```text
%AppData%\MemeMomo\settings.json
```

可在文件资源管理器地址栏输入 `%AppData%\MemeMomo\` 打开数据目录。正常备忘录、任务信息、单条提醒和回收站记录共同保存在 `memos.json`；状态定义在 `task-statuses.json`，本地图片在 `assets` 子目录。回收站用 `deletedAt`（UTC 删除时间）区分记录，没有单独文件。

需要备份偏好时，先完全退出应用，再复制 `settings.json`；需要完整备份时，复制整个 `MemeMomo` 数据目录。恢复时也应先退出，再放回相应文件，以免运行中的自动保存覆盖恢复内容。

设置文件不存在时使用默认值；损坏文件会尝试备份恢复，无法恢复时显示说明并阻止覆盖。任务状态目录单独保存在 `task-statuses.json`，恢复默认偏好不会删除它。备份文件与版本回退限制见[任务与状态](/#/docs/设置/任务与状态)。测试环境若显式设置了 `MEMEMOMO_APPDATA_DIR`，数据会位于该目录下的 `MemeMomo` 子目录。

## 原子保存、备份与恢复

应用先写临时文件，再原子替换目标 JSON。各类副本用途如下：

| 文件后缀 | 用途 |
| --- | --- |
| `.bak` | 日常替换保存留下的上一份目标文件。 |
| `.pre-tasks.bak` | 首次覆盖已有文件前保留的任务功能升级副本。 |
| `memos.json.pre-recycle-bin.bak` | 首次覆盖已有备忘录文件前保留的回收站升级副本。 |
| `.damaged-*` / `.recovered-*` | 读取损坏文件时保留的原始副本及成功读取的备份副本。 |

损坏时尝试有效 `.bak`；无法恢复或数据无法安全解释时，阻止相关文件继续覆盖并提示。先退出应用、保留现有文件，再用配套备份恢复并重启。完整备份同时保留 `memos.json`、`task-statuses.json`、`settings.json`、`assets` 及副本。

回退旧版需恢复升级前的完整数据。旧版可能忽略 `deletedAt` 而重新显示已删除记录，并在保存时丢失任务和删除信息；只替换程序文件不能保证兼容。

## 不在设置面板中的状态

这些字段由窗口操作自动维护，说明它们有助于理解“重启后记住了什么”和“重置影响什么”。

| 状态 | 如何改变 | 是否由“重置设置”恢复 |
| --- | --- | --- |
| 是否已经询问关闭行为 | 首次关闭主窗口时确认，或在设置中更改关闭行为。 | 是，恢复为尚未询问。 |
| 主窗口置顶 | 主窗口图钉、置顶快捷键或托盘菜单。 | 否，保留当前状态；初始默认置顶。 |
| 主窗口贴边状态、边缘、沿边位置及所在工作区 | 拖动主窗口贴边、沿边移动或拖出。 | 保留当前运行状态；关闭“启用贴边”会还原主窗口。 |
| 主窗口展开后的坐标和尺寸 | 移动窗口、拖动边缘或四角缩放。 | 否。 |
| 每条备忘录的便签标签弹出长度 | 展开贴边标签后拖动弧端把手。 | 否。 |
| 单个便签当前的置顶、任务栏显示状态 | 便签标题栏按钮或对应快捷键。 | 属于窗口临时状态，不单独写入设置文件；新窗口使用全局偏好和初始状态。 |
| 关于卡片的更新检测状态 | 点击“检测更新”。 | 不写入文件；同次运行中保留完成结果，未完成请求在离开时取消，重启重新开始。 |

设置分类、管理状态子页及草稿、筛选、列表收起偏好、回收站预览选择和提醒页输入只在本次运行或相应窗口会话中保留。它们不是跨重启存储字段；左右/上下布局按当前宽度计算。

保存标签弹出长度不等于保存每个便签窗口的打开状态和贴边位置；不要据此认为重启后会自动重建所有独立便签。
