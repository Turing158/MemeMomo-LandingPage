# 便签贴边标签


## 用途与触发

启用便签贴边后，拖动独立便签标题栏到工作区左边或右边，鼠标接近边缘约 40 个物理像素时出现贴边预览，释放后收起为 D 形标签。当前便签只支持左右边缘。

标签直边贴着工作区边界，弧端朝向屏幕内部。它有两种显示：

| 状态 | 显示内容 |
| --- | --- |
| 收起标签 | 标题的第一个文字元素和箭头，约 50 逻辑单位宽。 |
| 展开标签 | 更长的标题区域、箭头和弧端调长把手；仍然是标签，不显示正文。 |

## 单击与拖动

| 操作 | 结果 |
| --- | --- |
| 单击标签主体 | 在收起标签与展开标签之间切换。 |
| 按住标签主体沿边上下拖动 | 改变便签贴边位置。 |
| 按住主体向屏幕内部拖出 | 离开边缘到足够距离后恢复完整便签，再继续摆放。 |
| 展开后拖动弧端把手 | 调整标题标签的弹出长度；鼠标在把手处呈水平缩放光标。 |

**单击展开的是标题标签，查看或编辑正文需要拖出恢复完整便签。** 调整长度时应拖把手，移动或恢复窗口时应拖标签主体。

## 调整长度

左侧标签向右拖把手会加长，右侧标签向左拖会加长；反方向会缩短。弹出长度默认 100，允许 40–400 逻辑单位，总宽度还包含约 50 单位的收起部分。

松开把手后，长度按备忘录记忆，同一条记录的多个窗口共享这个偏好。它不代表便签窗口的位置、打开状态或所有贴边状态都会跨重启恢复。

## 其他行为

便签收起后仍关联原备忘录，其提醒不会被取消。关闭便签贴边功能会恢复为浮动窗口。系统通知的有效点击入口会尝试让对应标签恢复完整便签。

这里没有主窗口方块的托盘右键菜单；需要应用级命令时使用通知区域的托盘图标。完整便签的置顶、任务栏、编辑与关闭操作见[独立便签窗口](/#/docs/功能指南/独立便签窗口)。
