# 本地图片选择窗口

## 入口与用途

在 Markdown 工具栏或“更多格式”中点击“本地图片”，打开标题为“插入图片”的 Windows 文件选择窗口。它用于把图片复制到应用的数据目录，再插入当前备忘录。

文件列表、文件名栏、路径导航及打开 / 取消按钮由 Windows 提供，外观随系统变化。

## 选择与插入

1. 先在正文放置光标，或选中需要用图片替换的内容。
2. 打开“本地图片”，浏览图片所在文件夹。
3. 选择一张或多张图片；可使用 Windows 文件选择器的 `Ctrl` / `Shift` 多选。
4. 确认打开，应用保存图片后将其插入正文。

取消选择不改变正文。图片的默认替代文字取文件名去掉扩展名后的部分；插入后右键“编辑图片”可修改替代文字和路径，也可直接编辑源码。

## 格式与大小

| 项目 | 规则 |
| --- | --- |
| 可选格式 | PNG、JPG、JPEG、WebP、GIF、BMP、SVG。 |
| 单张大小 | 不超过 20 MiB，界面提示为“图片不能超过 20 MB”。 |
| 多选校验 | 所有文件都必须存在、格式受支持且未超限，否则拒绝这批插入。 |
| 图片保存 | 复制到 `%AppData%\MemeMomo\assets\`，正文引用相对资产路径；同内容、同规范扩展名的文件会复用。 |

**允许选择不等于一定能显示。** 当前使用 Windows/WPF 的位图解码能力，SVG 不会作为矢量图直接呈现，WebP 取决于环境解码支持，GIF 也不是动画播放器。显示异常时可先转成 PNG 或 JPG 后插入。

## 另外两种入口

- **粘贴图片**：复制截图或图片，在正文中按 `Ctrl + V` 或使用右键“粘贴”；位图会存为 PNG。也可从文件资源管理器复制图片文件后粘贴。
- **拖入图片**：把资源管理器中的受支持图片拖到正文区，出现“放开以插入图片”后释放。多个文件中混有不支持文件或超限图片时，不会只挑其中一部分写入正文。

图片插入也可能替换当前文字选区。上述操作处理图片，不能当作任意文件附件或 Markdown 文件导入使用。

## 插入后

图片先显示加载占位，再呈现可解码的图像。默认按自然大小显示，超过正文宽度时等比缩小；悬停可打开[图片宽度浮动工具栏](/#/docs/功能指南/图片宽度浮动工具栏)。

已有备忘录中的插图会随正文自动保存；新建草稿仍需按 `Ctrl + Enter` 提交。原图片文件可以移动，但备份时需要保留应用 `assets` 目录。网络图片入口另见[网络图片对话框](/#/docs/功能指南/网络图片对话框)。

回收站只读预览不会接受图片粘贴或拖入；请先恢复记录再修改。
