# 图片宽度浮动工具栏


## 入口与位置

将鼠标移到正文中已经加载的图片上，图片底部附近出现一条浮动工具栏。工具栏跟随图片和编辑区可见范围移动；图片滚出视口或鼠标离开后会收起。

## 宽度选项

| 选项 | 效果 |
| --- | --- |
| 自适应 | 小图按自然大小显示，宽图缩到可用正文宽度；保持比例，不主动放大小图。 |
| 25% | 图片宽度约为当前可用正文宽度的四分之一。 |
| 50% | 图片宽度约为当前可用正文宽度的一半。 |
| 75% | 图片宽度约为当前可用正文宽度的四分之三。 |
| 100% | 图片宽度填满可用正文宽度。 |

百分比相对于**编辑器正文宽度**，不是原图片像素宽度。选择百分比时小图也可能放大，因此可能出现清晰度下降。所有选项保持长宽比，窗口宽度变化后重新计算显示尺寸。

## 操作与保存

点击一个选项立即应用，当前选项会高亮。没有单独的保存或取消按钮；可重新选择“自适应”移除固定百分比。

尺寸保存在图片的 Markdown 引用后，例如：

```markdown
![示例](assets/example.png),50%
```

“自适应”会移除 `,50%` 一类后缀。更改尺寸遵循编辑器保存规则，且只改变显示与正文标记，不重采样或覆盖原始图片文件。

这是 MemeMomo 使用的图片宽度扩展语法，在其他 Markdown 软件中不保证有相同效果。当前浮动工具栏不提供裁剪、旋转、绘图或图片文件导出。
