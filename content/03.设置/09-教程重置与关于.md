# 教程、重置与关于

## 教程

位置：**设置 → 关于与维护 → 教程**。

点击打开使用教程，内容涵盖 Markdown 编辑、图片、分离便签、窗口调整、贴边、置顶、托盘和快捷键。教程按打开时的设置显示快捷键及其禁用状态；修改快捷键后重新从设置打开教程，可查看最新配置。

## 重置设置

位置：**设置 → 关于与维护 → 重置设置**。

点击后通过气泡询问“确定要恢复默认设置吗？”。确认后，语言、关闭行为、功能开关、托盘点击习惯、提醒方式、主题、便签配色、动效、贴边方块大小、默认新建类型与任务状态及六组快捷键恢复各分类文档列出的默认值，并自动保存。

重置只恢复偏好，不删除备忘录、回收站、图片、自定义状态目录或已设置的单条提醒。主窗口当前的位置、尺寸、贴边位置和置顶状态，以及按备忘录记忆的便签标签弹出长度会保留；已经打开的便签也不会因为默认置顶恢复而统一改变置顶状态。

## 关于与检测更新

位置：**设置 → 关于与维护**。

可查看 MemeMomo 的简介、当前版本和版权/许可证标识 `© StarFall · MIT License`。点击产品名旁的 GitHub 图标可在浏览器打开 [项目仓库](https://github.com/Turing158/MemeMomo)。

点击“检测更新”会联网读取 GitHub 发行信息，结果通过气泡反馈，操作按钮保留“检测更新”，发现不同版本时改为“查看新版本”。可能出现以下状态：

| 状态 | 含义与下一步 |
| --- | --- |
| 检测更新 | 尚未检测；点击开始。 |
| 检测中 | 请求正在进行，等待结果，期间不能重复点击。 |
| 有新版本 | 发行标签与当前显示版本不一致；点击可打开对应发行页面。 |
| 已是最新 | 发行标签与当前显示版本一致；本次设置会话中检测按钮禁用。 |
| 检测失败 | 请求失败或未得到有效发行信息；点击可重试。 |

当前实现按标签文本比较，忽略标签开头的 `v` 或 `V`，并不判断版本号大小。因此“有新版本”表示检测到不同版本，应在发行页面确认具体版本后自行下载。应用不会自动下载安装。

同次运行中离开再进入设置会保留已完成的检测结果，切换语言会翻译当前状态，重置偏好不会清空检测结果。若离开或隐藏时仍在检测，会取消本次请求并恢复“检测更新”，返回后可重新检测；重启应用从初始状态开始。
