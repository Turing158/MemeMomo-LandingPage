# 给开发者

适用版本：`v1.0.0`

## 技术栈

- **.NET 8 + WPF**：单目标 Windows 桌面应用，C# 编写。
- 无后端、无遥测，所有数据读写都发生在本机文件系统。

## 仓库结构

仓库内 `MemeMomo-wpf/` 是主项目：

| 目录 | 内容 |
| --- | --- |
| `Components/` | 自定义控件：MarkdownEditor、TimeWheelSelector、DateFieldSelector、通知宿主与各类对话框 |
| `Editor/` | 编辑器交互控制器：工具栏、输入、图片、表格、HTML 样式与剪贴板菜单 |
| `Markdown/` | Markdown 解析与文档模型：格式化、图片宽度语法、编辑会话、基础 HTML 显示 |
| `UI/` | 无边框窗口基础设施：贴边停靠、布局控制、动画与通知队列 |
| `Views/`、`ViewModels/` | 设置、提醒、托盘菜单、教程、任务状态管理与回收站等窗口及视图模型 |
| `Services/`、`Infrastructure/`、`Platform/` | 数据持久化、任务与提醒服务、Windows 托盘等平台服务 |
| `Resources/` | 设计令牌：Colors / Brushes / Controls / Icons 等 ResourceDictionary |

> 仓库中还存在 Avalonia 版本的迁移实验代码（`MemeMomo-avalonia/` 等），它们不属于 WPF 主项目。

## 从源码运行

```powershell
dotnet run --project MemeMomo-wpf/MemeMomo.csproj
```

## 发布

```powershell
dotnet publish MemeMomo-wpf/MemeMomo.csproj -c Release
```
