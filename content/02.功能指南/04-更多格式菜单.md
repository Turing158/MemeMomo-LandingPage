# 更多格式菜单


## 入口与显示条件

在 Markdown 工具栏点击省略号“更多格式”。窗口宽度不足时，部分按钮会收进此菜单；变宽后会重新显示在工具栏上。当所有功能都能放下时，“更多”按钮会隐藏，源码功能显示为 `MD` 按钮。

因此菜单条目数量随当前窗口宽度变化，已经显示在工具栏上的对应按钮通常不会在菜单里重复显示。

## 功能入口

| 条目 | 操作结果 |
| --- | --- |
| 表格 | 打开[表格插入面板](/#/docs/功能指南/表格插入面板)。 |
| 无序列表 | 为当前行或所选行应用列表格式。 |
| 有序列表 | 应用编号列表。 |
| 任务列表 | 应用可勾选的任务项。 |
| 引用 | 应用引用段落格式。 |
| 行内代码 | 切换短代码样式。 |
| 代码块 | 插入多行代码块。 |
| 分隔线 | 插入横向分隔线。 |
| 链接 | 打开[链接编辑对话框](/#/docs/功能指南/链接编辑对话框)。 |
| 本地图片 | 打开[本地图片选择窗口](/#/docs/功能指南/本地图片选择窗口)。 |
| 网络图片 | 打开[网络图片对话框](/#/docs/功能指南/网络图片对话框)。 |
| 编辑源码 | 打开[Markdown 源码对话框](/#/docs/功能指南/Markdown源码对话框)。 |

## 使用方法

先在正文定位或选中文字，再打开菜单。点击直接排版的条目后立即应用；选择链接、图片、源码等条目后，还需在对应界面完成操作。

鼠标离开菜单及其按钮区域后，菜单会延迟自动收起。菜单与编辑器之间切换会恢复正文焦点，单纯打开或关闭菜单不会保存或清空正文。

粗体、斜体、标题、删除线保留在工具栏基础区域；更具体的输入规则见[编辑器说明](/#/docs/功能指南/Markdown编辑器)。
