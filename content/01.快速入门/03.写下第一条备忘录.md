# 写下第一条备忘录

适用版本：`v1.0.0`

## 新增

在主窗口顶部的编辑器中输入内容，按 `Ctrl + Enter` 或点击保存按钮提交。两个细节：

- 新建草稿需要主动提交，停输不会自动新增；工具栏最左侧可以先把这条记录设为任务并选择初始状态。
- 编辑已有备忘录时按 `Ctrl + Enter`，效果是立即保存并保持当前编辑状态；点击工具栏的「新建备忘录」回到新建状态。

## 自动保存

编辑已有备忘录时，停输约 **500ms** 后内容会自动保存；按 `Esc` 可以恢复本次载入或最近一次手动保存时的正文。不需要手动点保存按钮。

## 编辑已有备忘录

**双击**列表中的卡片即可载入编辑，单击不会进入编辑。编辑器支持 Markdown 语法，详见 [Markdown 编辑器](/#/docs/功能指南/Markdown编辑器)。

## 标记任务状态

右键卡片可以切换普通备忘与任务、选择当前状态；任务卡片右侧的按钮会显示状态，点击即可完成，已完成或已取消时点击可重新打开。内置待办、进行中、暂缓、已完成、已取消五种状态，可以在「设置 → 任务与提醒 → 管理状态」中添加自己的状态。详见 [任务状态与筛选](/#/docs/功能指南/任务状态与筛选)。

## 删除

把鼠标悬停在卡片上，右侧会出现删除按钮；记录会移入回收站，气泡提供即时「撤销」，之后也可以从回收站预览、恢复或彻底删除。详见 [回收站](/#/docs/功能指南/回收站)。

## 快速收集想法

- 复制一段文字后按 `Ctrl + Alt + C`，文本会直接保存为一条备忘录，默认还会在鼠标附近显示对应便签；开关在「设置 → 通用」。
- 按 `Ctrl + Alt + Q` 在鼠标位置打开一张空白便签，`Ctrl + Enter` 首次保存后成为一条记录。
- 两组快捷键都可以在「设置 → 快捷键 → 快速添加」中修改或清空。
