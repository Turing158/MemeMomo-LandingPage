# 设置问题

适用版本：`v1.0.0`

| 现象 | 检查与处理 |
| --- | --- |
| 找不到“快速添加后自动显示便签” | 在「设置 → 通用」先开启“快速添加剪贴板内容”。 |
| 快速添加快捷键按钮变灰 | 快速添加总开关已关闭，开启后再配置。 |
| 找不到“贴边方块大小” | 先开启主窗口的“启用贴边”；便签贴边不会显示此卡片。 |
| 找不到“切换便签任务栏图标”快捷键 | 先开启“便签窗口任务栏图标”。 |
| 快速添加后没有弹窗 | 检查自动显示开关；关闭它时仍会收集文本。确认剪贴板含非空文本。 |
| “管理状态”里改了状态没生效 | 该页字段是局部草稿，需要点击“保存状态”提交；返回箭头不会保存。 |
| 快捷键保存后无反应 | 检查对应功能是否开启、快捷键是否留空，以及组合是否被其他应用占用。 |
| 关闭主窗口后仍有提醒 | 关闭行为可能是“最小化托盘”；要停止本次运行，请使用“退出应用”。 |
| 已改默认置顶，旧便签却没变化 | 默认值只控制新窗口，旧窗口请用图钉单独调整。 |
| 改主题后便签背景没跟着变 | “便签配色”可能选了固定颜色，改为“跟随主题”。 |
| 主窗口可贴边，便签不能贴边 | 两个开关独立；便签目前只支持左、右边缘。 |
| 回收站里找不到刚删的记录 | 回收站入口在标题栏数量徽标菜单顶部；恢复的记录若被当前筛选隐藏，先“清除筛选”。 |
| 提醒没有显示 | 确认已点击“设置提醒”且应用正在运行；系统通知模式还需检查 Windows 通知权限与免打扰。 |
| 检测更新失败 | 确认网络可以访问 GitHub，再点击重试；无有效发行记录也会检测失败。 |
