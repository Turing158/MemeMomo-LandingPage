# 代码语言对话框

## 入口与操作

右键正文中的代码块，选择“编辑代码语言”。输入语言名称，例如 `csharp`、`python`、`json` 或 `c++`，点击保存或在输入框按 `Enter`；取消、关闭或 `Esc` 放弃修改。

名称允许字母、数字及 `_ - + # .`，首尾空白会去掉，不允许中间空格。留空可清除语言标签，无效输入通过气泡提示。

## 修改范围

保存只调整代码块的语言标记，保留代码内容；围栏代码更新首行语言，HTML `pre` 更新语言属性，缩进代码指定语言后转换为围栏代码。修改遵循正文保存和撤销规则。

语言标签用于说明代码种类，不执行代码，也不代表提供编译、运行或完整 IDE 功能。悬停代码块可复制代码正文；右键“删除代码块”直接删除整块，可通过正文撤销恢复。回收站保留代码复制，不提供语言修改或删除入口。
