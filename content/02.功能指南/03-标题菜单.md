# 标题菜单


## 入口与布局

在 [Markdown 编辑器](/#/docs/功能指南/Markdown编辑器)工具栏点击 `h` 按钮，打开四个选项：H1 一级标题、H2 二级标题、H3 三级标题、H4 四级标题。独立便签需先显示工具栏。

## 操作

1. 将光标放到需要处理的一行，或选择多行。
2. 打开标题菜单，选择目标级别。
3. 当前行或选中行转换为该级别标题，返回编辑器继续输入。

| 选项 | 保存的 Markdown 前缀 |
| --- | --- |
| H1 一级标题 | `# ` |
| H2 二级标题 | `## ` |
| H3 三级标题 | `### ` |
| H4 四级标题 | `#### ` |

如果选中范围内的行已经全部使用同一级别，再选该级别会移除标题格式。改选其他级别会替换原级别；标题效果作用于整行，不是只改变选中的几个字。

菜单关闭后可以继续原位置的编辑。标题修改遵循编辑器保存规则；这里不需要另点“确定”，也不会创建新的备忘录。
