# 图片编辑对话框

## 入口与字段

在可编辑正文中右键图片，选择“编辑图片”。支持当前编辑器已识别的 Markdown 图片和 HTML `img` 图片。

| 字段 | 作用 |
| --- | --- |
| 图片源码 | 编辑这一张图片的完整引用，保留原有 Markdown 或 HTML 形式。 |
| 替代文字 | 修改 Markdown 的方括号文字或 HTML 的 `alt`。 |
| 图片路径 | 修改本地资产路径或受支持的 HTTPS 地址。 |
| 保存 / 取消 | 将修改应用到正文，或放弃本次修改。 |

源码与替代文字、路径同步。原有宽度和其他受支持属性在字段编辑时保留；显示宽度也可在[浮动工具栏](/#/docs/功能指南/图片宽度浮动工具栏)调整。

## 校验与保存

图片必须保留完整的 `![]()` 或 `img` 结构，不能在此将图片改成普通文字或切换两种源码形式。无法识别的结构、属性或路径会显示校验气泡，不能保存；删除图片请使用右键“删除图片”。

点击保存或按 `Ctrl + Enter` 应用；替代文字、路径输入框中也可按 `Enter`，源码框中普通 `Enter` 用于输入。取消、关闭或 `Esc` 保留原图。应用后遵循当前备忘录的自动保存或首次提交规则。

此对话框编辑引用，不裁剪或覆盖图片文件，也不把网络图片自动下载到本地。回收站预览不提供修改入口。
