# 链接编辑对话框


## 打开方式

在编辑器工具栏或更多菜单点击“链接”，也可按 `Ctrl + K`。

- 新建链接时，可以先选中文字作为链接文本；没有选区时提供默认的“链接文本”。
- 光标位于现有链接上时，会载入该链接的文字和地址，进入“编辑链接”。

## 界面元素

| 元素 | 用途 |
| --- | --- |
| 链接文本输入框 | 备忘录中显示的可读文字，不能为空。 |
| 链接地址输入框 | 实际打开的完整地址，不能为空。 |
| 地址清空按钮 | 清空地址并把焦点留在该输入框。 |
| 字段错误提示 | 指出文字缺失、地址不完整或协议不支持。 |
| 插入链接 / 保存修改 | 输入有效时可用，根据当前模式显示不同名称。 |
| 取消 / 右上角关闭 | 放弃本次修改。 |

## 可接受地址

| 类型 | 示例 |
| --- | --- |
| HTTPS 网页 | `https://example.com` |
| HTTP 网页 | `http://example.com` |
| 邮件地址 | `mailto:hello@example.com` |

不支持仅填写 `example.com`、仅填写 `https://`、本地文件路径或其他协议。输入两端空白会去掉，校验通过只表示格式可用，不保证网页在线或邮件客户端已安装。

## 确认、取消与打开链接

点击确认按钮，或在输入框中按 `Enter`，将链接作为 `[文字](地址)` 保存到当前编辑内容。新链接替换对应文字选区，编辑已有链接会替换原链接。

点击取消、右上角关闭或按 `Esc`，保留原正文及原链接。对话框关闭后返回编辑器；已有备忘录的修改会按编辑器规则保存。

在正文中 **按住 `Ctrl` 再点击链接**，才会调用系统关联程序打开网页或邮件地址。普通点击用于定位光标和编辑。
