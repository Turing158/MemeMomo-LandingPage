# 主窗口贴边方块

## 用途与触发

主窗口贴边用于把整个备忘录管理界面收起为带应用图标的小方块，减少桌面占用。启用主窗口贴边功能后，按住标题栏向屏幕工作区边缘拖动，拖动中的鼠标接近边缘约 40 个物理像素时进入贴边预览，释放后固定。

支持左、右、上、下四边及四个角落；工作区会考虑任务栏等占用，不总是显示器的最外边界。

## 方块上的操作

| 操作 | 结果 |
| --- | --- |
| 按住左键，沿边缘拖动 | 调整方块沿边的位置。 |
| 继续拖到角落 | 形成对应的角落贴边位置。 |
| 按住左键，向屏幕内侧拖出 | 超过脱离距离后恢复完整主窗口，可继续拖动摆放。 |
| 右键 | 打开与托盘图标共用的[托盘菜单](/#/docs/功能指南/托盘菜单)。 |

单击方块不是展开主窗口的操作；需要向内拖出，或使用托盘“打开备忘录”及 `Ctrl + Alt + N` 恢复。鼠标悬停也不会自动展开完整界面。

## 状态与记忆

方块默认大小为 44 逻辑单位，可由设置调整到 30–75。它保留主窗口置顶等状态，并记忆贴边边缘、沿边位置、工作区以及展开后的尺寸和位置。下次启动可恢复贴边状态。

收起后备忘录和提醒继续运行。本次运行中恢复会回到原备忘录、回收站或设置页；展开后的备忘录工作区按当前宽度重新决定上下或左右布局。页面与列表收起偏好不作为跨重启设置保存。关闭主窗口贴边功能会恢复完整主窗口。更换显示器、分辨率或缩放比例后，位置会按可用工作区调整。

这是主窗口的方块；独立便签使用左右两侧的 D 形标签，操作见[便签贴边标签](/#/docs/功能指南/便签贴边标签)。
