# Windows 系统提醒通知


## 何时出现

为备忘录[设置提醒](/#/docs/功能指南/提醒设置窗口)后，到期时默认由 Windows 显示系统通知。应用需处于运行状态，隐藏在托盘中也可以；完全退出后不再检查时间。

通知由 Windows 绘制，具体外观、出现位置、声音和展示时长受系统版本与设置控制，并非应用内另一个自定义面板。

## 通知内容和操作

通知标题取备忘录标题，正文取摘要；没有合适摘要时提供提醒或点击查看的提示，过长内容会截断。它不会显示整篇 Markdown 或可编辑表格。

| 操作 | 结果 |
| --- | --- |
| 及时点击当前有效通知 | 打开或复用对应便签；贴边便签会尝试恢复为完整窗口。 |
| 关闭通知或等待消失 | 结束本次通知显示，不删除备忘录，也不会重新安排提醒。 |
| 从通知中心点击较早条目 | 当前实现不保证定位原便签，可能只恢复主窗口，也可能没有系统回调。 |

当前通知没有“稍后提醒”“完成任务”或延后按钮。要再次提醒，打开便签重新安排时间。

## 三种到期显示方式

| 已配置方式 | 到期效果 |
| --- | --- |
| 系统通知（默认） | 依次发送 Windows 通知。 |
| 应用内窗口 | 打开或复用对应独立便签。新窗口按主窗口所在工作区居中放置。 |
| 两者 | 同时处理应用内便签与系统通知。 |

应用内窗口是普通的[独立便签](/#/docs/功能指南/独立便签窗口)，不是额外的闹钟对话框。复用的便签若已经贴边，自动到期显示可能保持标签状态；有效通知点击才会尝试主动拖出式恢复。

多条同时到期时按提醒时间顺序处理，系统通知逐条发送，因此后面的通知可能稍后出现。等待通知超过 32 条时，“系统通知”模式对超出的条目改用应用内便签显示。

## 提醒状态与系统限制

- 到期处理后清除该条提醒时间，即使通知被系统抑制，也不会每天或每次启动重复触发它。
- 应用完全退出期间不会显示通知；下次启动可补处理仍未触发、但已经过期的记录。
- Windows 关闭通知或开启免打扰时，通知可能不弹出；应用不会因此自动切换到应用内窗口。
- 点击历史通知不可靠时，可通过托盘或 `Ctrl + Alt + N` 找回主窗口，再查看对应记录。
- 删除备忘录会取消应用中对应的待处理通知安排，但不能据此保证 Windows 已显示的历史条目立即消失。
