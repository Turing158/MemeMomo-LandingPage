# 时间滚轮面板


## 所在位置与布局

时间滚轮位于[提醒设置窗口](/#/docs/功能指南/提醒设置窗口)日期字段下方，三个独立数字轮分别表示“时”“分”“秒”，中间的高亮位置代表选中值。

小时使用 24 小时制，为 00–23；分钟和秒为 00–59。它没有直接输入数字的文本框。

## 鼠标操作

| 操作 | 作用 |
| --- | --- |
| 在某列上滚动鼠标滚轮 | 调整该列数字。 |
| 按住数字列上下拖动 | 连续滚动；启用动效时释放后可有惯性，最后吸附到一个整数。 |
| 点击中心值上方或下方的步进区域 | 分别向前或向后调整一个数字。 |

三个滚轮分别调整，跨边界时循环，例如分钟 59 之后回到 00。**单列环绕不会自动替你增加小时或日期**；跨午夜或按相对时长安排时，用提醒窗口的快捷按钮更合适。

## 键盘操作

先让目标数字轮获得焦点，再操作：

| 按键 | 变化 |
| --- | --- |
| `↑` / `←` | 当前列减 1。 |
| `↓` / `→` | 当前列加 1。 |
| `PageUp` | 当前列减 5。 |
| `PageDown` | 当前列加 5。 |

需要精确选值时可用方向键微调。动效关闭时，调整会直接到目标值。

## 与日期、保存的关系

最终提醒时间由“所选日期 + 时分秒”组合，单独滚动时间不会保存提醒。调整完成后点击“设置提醒”；若完整时间过早，主面板会提示错误。

“1分钟后”等快捷按钮会同时更新日期和三个滚轮。打开已有提醒时，滚轮预先显示已保存提醒的时间。
