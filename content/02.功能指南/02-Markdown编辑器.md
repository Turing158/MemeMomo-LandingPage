# Markdown 编辑器


## 用途与所在位置

主窗口顶部和独立便签正文共用同一个编辑器。它在单个编辑区域中展示排版结果，隐藏已识别的部分 Markdown 标记，同时保存原始 Markdown。需要直接处理标记时，打开[源码对话框](/#/docs/功能指南/Markdown源码对话框)。

上方是格式工具栏，正文区可输入、选择和滚动；空内容显示“写点什么…”，右下角短暂或持续显示操作状态。独立便签的工具栏默认隐藏，可从便签标题栏展开。

## 支持的内容

| 内容 | 使用方法与效果 |
| --- | --- |
| 粗体、斜体、删除线 | 选中文字后点 `B`、`I`、`S`，或输入相应 Markdown；可切换已有格式。 |
| 标题 | 点 `h` 打开[标题菜单](/#/docs/功能指南/标题菜单)，选择 H1–H4。 |
| 无序、有序、任务列表 | 从工具栏或更多菜单插入；任务项可点击复选框切换完成状态，并保存到正文。 |
| 引用 | 插入带引用样式的段落，支持继续输入与退出引用。 |
| 行内代码 | 把短代码放入等宽字体样式中，Markdown 使用反引号。 |
| 代码块 | 插入多行代码区域；可显示源码中指定的语言标签，并提供复制代码按钮。 |
| 分隔线 | 插入横向分隔内容的线条，可选中、跨越或删除。 |
| 链接 | 打开[链接编辑对话框](/#/docs/功能指南/链接编辑对话框)填写文本和地址。 |
| 表格 | 用[网格面板](/#/docs/功能指南/表格插入面板)选择大小，再在[单元格界面](/#/docs/功能指南/表格编辑与右键菜单)中编辑。 |
| 图片 | 支持本地选择、剪贴板、文件拖入及 HTTPS 图片，另有[宽度工具栏](/#/docs/功能指南/图片宽度浮动工具栏)。 |
| 下划线、高亮 | 可在源码中使用 `<u>文字</u>`、`<mark>文字</mark>`；当前工具栏没有对应按钮。 |

窗口变窄时，放不下的按钮会进入[更多格式菜单](/#/docs/功能指南/更多格式菜单)。选中多行后，标题、列表等操作可作用于相应行；未选中文字时，行内格式可能插入待填写位置，块格式作用于当前行或插入位置。

## 常用按键

| 按键 | 正文中的作用 |
| --- | --- |
| `Ctrl + Enter` | 新建状态下提交一条记录；已有记录中立即保存并留在当前编辑状态。 |
| `Enter` | 普通段落换行；在列表、引用、表格等结构中按对应规则处理。 |
| `Ctrl + B` / `Ctrl + I` | 切换粗体 / 斜体。 |
| `Ctrl + K` | 插入链接，或编辑光标所在的现有链接。 |
| `Ctrl + C` / `Ctrl + X` / `Ctrl + V` | 复制、剪切、粘贴；有图片数据时可走图片插入。 |
| `Ctrl + A` | 选择当前文本编辑区域中的全部内容。 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做编辑操作；不等于恢复被删除的备忘录。 |
| `Esc` | 恢复当前编辑基准；新建状态下清空未提交草稿。 |
| `Ctrl` + 点击链接 | 用系统关联程序打开受支持地址。 |

表格单元格拥有自己的输入处理，不能把正文中的全部格式快捷键直接套用到单元格。菜单或对话框打开时，先按其自身的取消和确认规则操作。

## 列表与引用的连续输入

- 有内容的列表项中按 `Enter` 会续接下一项，有序列表继续编号，新任务项为未完成状态。
- 空列表项中再按 `Enter`，标记会变成等宽缩进，作为上一项的续行；在空续行中再次按 `Enter` 可恢复后续列表项。
- 已有内容的缩进续行按 `Enter`，保留相同缩进。空续行按 `Backspace` 可返回上一行末尾。
- `Shift + Enter` 可断开当前列表段，下方同级有序列表重新从 1 编号；在行中使用时会处理该行余下内容的缩进。
- 列表上下文中可用 `Tab` / `Shift + Tab` 增加或减少缩进。删除键在标记范围内会整体处理标记，不需要逐个删除隐藏符号。
- 引用中按 `Enter` 继续引用；空引用行再按 `Enter` 去除引用前缀。

## 代码与分隔线

将鼠标移到代码块上可显示“复制代码”。点击后复制代码正文，成功显示“已复制代码”，失败显示“复制失败”；不会执行代码。空代码块可用 `Ctrl + Backspace` 删除。

方向键进入分隔线时会以边框表示选中，再按方向键可移到其上方或下方；选中后按 `Backspace` / `Delete` 删除线条，按 `Enter` 转到下方输入位置。紧邻分隔线使用删除键也会按边界规则处理。

## 保存与恢复

| 状态 | 保存规则 |
| --- | --- |
| 新建备忘录 | 必须点击保存或按 `Ctrl + Enter`；停输不会自动新增。 |
| 编辑已有备忘录 | 停输约 500ms 自动保存；保存按钮或 `Ctrl + Enter` 立即保存。 |
| 源码、图片、表格等修改返回正文 | 同样遵循当前的新建 / 已有记录规则。 |

`Esc` 的恢复基准初始为载入时的正文，**手动立即保存成功后会更新基准**，自动保存不会更新。例如载入 A，改成 B 并自动保存后按 `Esc`，会写回 A；如果已手动保存 B，再改成 C 后按 `Esc`，则写回 B。

这是一项正文恢复操作，会清除当前编辑器的撤销记录；它不关闭便签，不取消提醒，也不是永久版本历史。

## 状态提示

| 提示 | 含义 |
| --- | --- |
| 未保存 | 内容已变化；已有记录会等待自动保存，新建内容需主动提交。 |
| 保存中 | 正在提交，避免重复操作。 |
| 已保存 | 本次保存成功，提示稍后消失。 |
| 内容不能为空 | 新建内容没有可用摘要内容，补充文字后再提交。 |
| 保存失败或具体错误 | 本次保存未成功，保留正文并检查错误原因。 |
| 放开以插入图片 | 拖入的图片文件通过初步检查，可以在编辑器释放。 |

图片格式、大小与加载问题分别见[本地图片](/#/docs/功能指南/本地图片选择窗口)和[网络图片](/#/docs/功能指南/网络图片对话框)。
