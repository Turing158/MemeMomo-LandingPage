# 独立便签窗口

## 用途与打开方式

独立便签用于把一条备忘录单独放在桌面上阅读和编辑。可以从主窗口将卡片拖出并释放；剪贴板快速添加默认也会显示便签，提醒到期或点击系统通知也可能打开它。

便签对应原来的同一条备忘录，分离显示不会从列表移除记录，也不会自动复制出一份独立正文。

也可按 `Ctrl + Alt + Q` 打开空白便签，首次保存后才成为一条记录。已有未保存的快速添加便签时，重复快捷键会将它移到鼠标位置并保留内容。首次保存前关闭会在当前便签显示「保存／不保存／取消」确认气泡，保存成功后沿用下述普通便签行为。

## 界面布局

| 区域或按钮 | 作用 |
| --- | --- |
| 标题 | 根据备忘录摘要显示，内容变化时同步更新。 |
| 时钟 | 切换到便签内的[提醒设置页](/#/docs/功能指南/提醒设置窗口)，再次点击返回；高亮表示正在提醒页，小圆点表示已设置未来提醒。 |
| 工具栏开关 | 显示或隐藏正文 Markdown 工具栏，包括左侧状态选择器和完成/重新打开按钮，默认隐藏。 |
| 任务栏按钮 | 在任务栏显示或隐藏当前便签；只有启用便签任务栏功能时才出现。 |
| 图钉 | 切换当前便签置顶；新便签默认置顶，实际由用户偏好决定。 |
| 关闭 | 保存待完成的编辑后关闭当前便签，保留备忘录和提醒。 |
| 正文 | 可直接编辑的 [Markdown 编辑器](/#/docs/功能指南/Markdown编辑器)。 |
| 底部时间 | 显示记录的创建时间，点击切换相对时间和更完整的时间文本。 |

时间戳来自创建时间，不代表最近编辑或提醒时间。切换时间显示方式不修改记录。

## 编辑与关闭

正文停输约 500ms 后自动保存，`Ctrl + Enter` 立即保存，`Esc` 恢复当前编辑基准。工具栏隐藏时仍能输入和使用编辑快捷键。

关闭按钮会先尝试完成编辑；保存失败时不会按正常流程直接关闭。关闭便签只收起这个窗口，应用和提醒仍可运行；要删除内容，到主窗口删除卡片。源记录被删除时，对应便签会关闭。

## 移动、缩放与任务栏

拖动标题栏移动，拖动边缘或四角缩放。默认便签大小为 375 × 375，最小为 280 × 180 逻辑单位；提醒页沿用同一窗口尺寸，内容不足时滚动。靠近工作区左、右边缘时，可变成[便签贴边标签](/#/docs/功能指南/便签贴边标签)。

任务栏按钮只影响当前便签是否拥有任务栏入口，不会隐藏便签本身；全局 `Ctrl + Alt + B` 对最近激活的便签执行同类切换。图钉也只改变当前便签，新窗口默认值不会持续覆盖手动切换。

便签配色在“设置 → 外观”中选择，可跟随主题或使用七种预设颜色；本窗口没有单独的配色面板。

## 提醒页与正文往返

进入提醒页后，正文、格式工具和底部时间暂时隐藏，工具栏开关禁用；正文选区、撤销历史和工具栏偏好保留。保存提醒成功、取消提醒成功、点击“取消”或再次点击时钟都会返回正文。普通取消不会清除已有提醒；关闭标题栏窗口按钮会关闭整个便签。

临时隐藏或贴边不会放弃提醒页的输入，恢复窗口后可继续；返回正文后再次进入则按最新已保存提醒初始化。未保存的快速新建草稿需要先创建记录，才能设置提醒或使用便签贴边。

## 多个窗口与复用

- 默认关闭“重复便签”：再次拖出同一条记录，优先复用已打开的便签，移动到目标位置并激活。
- 开启“重复便签”后，拖出同一条记录可以创建多个窗口；它们仍关联同一条记录，不能当作独立副本使用。
- 同一条记录的编辑在主窗口和便签之间协调交接，切换活动编辑位置时会尝试先保存原编辑。
- 已经贴边的现有便签被普通拖出入口或应用内提醒复用时，可能保持原标签状态；点击当前有效系统通知则会尝试恢复为完整窗口。
- 重启不会自动重建上次所有独立便签及其位置；按记录记忆的是贴边标签弹出长度等有限状态。

## 任务状态

便签编辑器工具栏最左侧提供与主窗口相同的状态选择、完成和重新打开入口，随工具栏一起显示或隐藏。窄窗口中状态名称会省略，悬停可查看完整名称。状态改变同步到所有已打开的副本，不关闭便签，不重置正文选区、置顶或配色。已完成/已取消任务的提醒入口不可提交，重新打开后可安排新的提醒。详见[任务状态与筛选](/#/docs/功能指南/任务状态与筛选)。
