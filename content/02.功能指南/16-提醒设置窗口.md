# 提醒设置页

## 入口与页面切换

在已保存的[独立便签](/#/docs/功能指南/独立便签窗口)标题栏点击时钟，为当前记录安排一次提醒。提醒表单在同一个便签内部打开，再次点击时钟返回正文；每个便签管理自己的提醒输入，提交后同一记录的已保存提醒会同步。

高亮表示正在提醒页；时钟旁小圆点表示已有未来提醒，悬停可查看具体时间。未保存的快速新建草稿需先保存；已完成或已取消任务需先重新打开。

## 界面布局

| 区域 | 功能 |
| --- | --- |
| 原便签标题栏 | 显示备忘录标题；时钟切换页面，置顶、任务栏和关闭继续作用于当前便签。 |
| 当前提醒 | 有未来提醒时显示最新已保存时间，没有时隐藏。 |
| 快捷时间 | 1分钟后、10分钟后、半小时后、1小时后。 |
| 日期字段 | 打开[日期选择浮层](/#/docs/功能指南/日期选择浮层)。 |
| 时、分、秒 | 使用[时间滚轮](/#/docs/功能指南/时间滚轮面板)调整。 |
| 固定底部操作区 | 取消提醒（存在未来提醒时）、取消、设置提醒。 |
| 气泡 | 显示日期时间校验、正在保存、成功或失败。 |

表单沿用便签尺寸，可拖动窗口边缘缩放。高度不足时表单滚动，底部按钮保持可达；宽度不足时快捷时间和底部按钮换行。正文及其工具栏暂时隐藏，返回时恢复原编辑位置与工具栏偏好。

## 设置或修改

1. 点击时钟进入。存在未来提醒时载入该时间，否则预选当前时间约 10 分钟后。
2. 选择日期和时分秒，或点击快捷时间。
3. 点击“设置提醒”。校验并保存成功后返回正文，失败留在提醒页供重试。

快捷按钮从点击时计算，并同步更新日期，跨午夜也有效。时间使用本机本地时间、精确到秒，提交时必须晚于当前时间约 1 秒。

调整字段只修改本次草稿，必须点击“设置提醒”才保存。一条记录只有一个提醒时间，再次提交替换原安排。

## 返回、取消与关闭

| 操作 | 结果 |
| --- | --- |
| 再次点击时钟或点击“取消” | 放弃本次时间调整，返回正文，已有提醒保留。 |
| 点击“取消提醒” | 清除已保存提醒，持久化成功后返回正文。 |
| 按 `Esc` | 先关闭日历等浮层；没有浮层且未提交时，按取消返回正文。 |
| 点击标题栏关闭或 `Alt + F4` | 关闭整个便签，按正常流程收尾提醒提交和正文保存。 |
| 暂时隐藏、失焦或贴边收起 | 保留当前页面和未提交时间，恢复后继续。 |

提交过程中不能重复保存或切换页面；通过气泡显示进度和失败原因。返回后再次进入会读取最新已保存值，已取消的提醒草稿不再恢复。

若在其他窗口完成或取消任务，提醒页会反映不可提醒状态并禁止提交，但仍可返回正文。记录被删除到回收站后，对应便签会关闭。旧页面不能向已删除或已变更生命周期的记录提交。

## 到期与任务规则

普通备忘、待办、进行中和暂缓任务可以设置提醒。任务完成或取消会清除提醒，重新打开不会恢复旧提醒。

应用需保持运行或驻留托盘；完全退出后停止计时，下次启动可补处理仍有效的到期安排。到期处理后清除该时间。全局方式在“设置 → 任务与提醒 → 提醒方式”中选择，见[系统提醒通知](/#/docs/功能指南/Windows系统提醒通知)。
