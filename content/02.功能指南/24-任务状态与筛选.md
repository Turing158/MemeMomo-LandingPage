# 任务状态与筛选

普通备忘适合记录资料和想法；任务备忘额外包含状态。旧数据全部作为普通备忘载入，不会根据 Markdown 复选框或提醒时间自动转换。

## 创建和转换

在主窗口编辑器工具栏最左侧选择普通备忘或任务。选择任务时可指定初始状态；默认创建偏好在设置的「任务与提醒」中配置。编辑已有记录时，这里显示该记录的状态。

右键点击备忘录卡片打开菜单，可以将普通备忘设为任务，也可以直接选择状态。卡片获得键盘焦点后，按菜单键或 Shift + F10 同样可以打开菜单。正常任务卡片左侧竖线显示状态色，右侧按钮显示当前状态图标；悬停按钮展开当前状态名称。点击未结束任务的按钮会完成任务，点击已完成或已取消任务的按钮会重新打开；提示同时说明当前状态和点击动作。卡片悬停时按钮向左让出删除位置。

卡片中已移除状态下拉框，选择任意状态或「转为普通备忘」请使用右键菜单。主窗口编辑器及独立便签工具栏仍保留状态选择器和完成/重新打开入口，各窗口同步同一条记录的状态。

转换保留正文、ID、创建时间、手动顺序和已打开的窗口。状态变化不会抢占正文编辑权；编辑正文或按 Esc 恢复正文都不会自动重新打开任务。

类型/状态、筛选及默认状态菜单用强调底色和右侧勾号标记当前选项。状态选择菜单直接列出状态，不再显示重复的分类小字。打开菜单时不会自动高亮第一项；方向键移动焦点、Enter 选择、Esc 关闭并返回入口。普通备忘不会误标默认任务状态，已有记录的「设为任务」「转为普通备忘」是操作项，不显示选中标记。

## 五种基础类别

| 类别 | 含义与提醒 |
| --- | --- |
| 待办 | 未结束，可设置提醒。 |
| 进行中 | 未结束，可设置提醒。 |
| 暂缓 | 未结束，保留已有提醒，也可以主动取消提醒。 |
| 已完成 | 任务结束，清除提醒并取消应用内的通知队列记录。 |
| 已取消 | 任务结束，但不计为完成；提醒处理与完成相同。 |

所有状态均可直接切换。「重新打开」优先恢复最近一个有效、未隐藏的未结束状态，否则使用当前默认状态。旧提醒不会恢复。同一结束类别内更换状态保留本次结束时间，完成与取消之间切换则记录新的结束时间。

## 筛选与排序

点击主窗口标题栏数字徽标打开统一筛选菜单。顶部依次为带数量的「回收站」和「清除筛选」，下面是类型、任务状态分组。选择「未结束」查看待办、进行中和暂缓，也可筛选基础类别或具体状态。

选择普通备忘会清除状态条件并禁用状态选项；先选择全部备忘或任务备忘，再设置任务状态。设置状态条件会切换到任务；已完成筛选不包含已取消。

徽标悬停、键盘聚焦或打开菜单时展开摘要：无筛选为「全部」，仅类型时为「普通」或「任务」，组合条件为「任务 | 状态」。长名称省略，完整条件可看提示和菜单；菜单项较多时可滚动。

筛选菜单的任务状态选项带有 SVG 图标：“状态不限”显示筛选线条，“未结束”显示时钟，各状态沿用对应图标；自定义状态（包括已隐藏状态）使用其配置的图标。

只有内置状态时，每个类别只显示一次。类别下存在自定义状态或状态缺失的任务时，「进行中（全部）」等入口筛选整个类别，下面的「进行中」和自定义名称用于精确筛选单个状态；隐藏状态仍可用于筛选已有任务。

标题栏数字表示当前正常列表的可见条数，0 条仍保留；提示显示可见数与总数。回收站中数字改为回收站条数，设置页和回收站期间禁用筛选入口。列表及筛选结果保持原有手动顺序，不再提供独立的排序筛选框。

只有「全部备忘＋状态不限」支持列表内重排。筛选时仍能拖出可见卡片，打开独立便签。改变条件或状态会取消进行中的拖动，避免提交过期索引。

筛选不删除记录、不改写保存顺序，也不缩小提醒检查范围。正在编辑或刚创建的记录不符合条件时，界面提供「显示全部」入口，编辑草稿继续保留。筛选只在本次运行中有效。

## 自定义状态与保存错误

在「设置 → 任务与提醒」中打开内嵌的「管理状态」子页，添加、修改、排序或隐藏状态。名称允许 1～24 个 Unicode 文本元素，不可与当前语言的其他显示名称重复；图标和颜色使用预设。隐藏后，已有任务仍显示该状态，筛选也仍可找到。

8 个图标预设使用统一圆角线条的 SVG：圆环、播放、暂停、勾选、叉号、星标、旗帜和时钟。菜单、主窗口与独立便签状态标签、管理列表和预览使用同一套图形，颜色随主题与选中状态变化。管理面板的图标选项同时显示图形和名称。

内置状态保留固定名称与类别，不能删除。默认状态必须可选且未结束，隐藏它之前先更改默认。删除自定义状态须选择替代状态；类别调整与删除都会显示影响任务数、目标类别和取消提醒数。确认后迁移，正文保持不变。

状态保存失败会在所属窗口显示错误气泡，可以重试。迁移失败会保留源定义；若程序在类别迁移中退出，重启后可能保留同名的旧定义和新定义，可核对使用数后用删除迁移完成清理。显示「状态已缺失」时，原始引用仍保留，选择有效状态即可修复该任务。

## 回收站与状态管理导航

回收站内保留状态信息用于查看，不允许完成、重新打开或修改状态；恢复记录后再操作。管理状态页的返回箭头只返回原设置分类，标题栏齿轮返回原工作区；同次运行再进入设置时保留管理页及未保存字段。

数据文件、备份和回退方式见[任务与状态设置](/#/docs/设置/任务与状态)。
