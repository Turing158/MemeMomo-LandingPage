# 主窗口

## 用途与打开方式

主窗口是备忘录的管理入口，负责创建记录、编辑正文、浏览摘要、删除和调整顺序。启动应用后显示主窗口或上次保存的贴边状态；也可通过托盘菜单的“打开备忘录”、托盘图标默认双击或 `Ctrl + Alt + N` 找回。

重复启动程序会尝试唤起已经运行的实例。主窗口默认不显示任务栏图标，因此任务栏没有按钮不代表应用已经退出。

## 界面布局

| 区域 | 内容与作用 |
| --- | --- |
| 标题栏左侧 | 应用图标、MemeMomo 名称、可见数量徽标；0 条时仍显示，点击徽标打开筛选与回收站菜单。左右布局下应用图标可切换列表显隐。 |
| 标题栏右侧 | 设置、置顶、最小化、关闭。齿轮进入主窗口内的设置页，再次点击或点页内返回箭头返回原工作区。 |
| 编辑区 | [Markdown 编辑器](/#/docs/功能指南/Markdown编辑器)的工具栏最左侧提供类型/任务状态选择，用于新建或编辑当前备忘录。 |
| 列表 | 卡片包含标题、副标题、创建时间和删除按钮；任务以左侧状态色竖线及右侧状态按钮表示当前状态。 |
| 空列表 | 显示新建引导，按布局提示在上方或右侧输入；筛选无结果时提供清除筛选入口。 |

窗口宽度小于 660 DIP 时，上方编辑、下方列表；达到 660 DIP 后，左侧列表、右侧编辑。展开列表至少 320 DIP，空间充分时两栏按 1:3 分配。左右布局下点击应用图标可收起或展开列表；上下布局始终显示列表，再次拉宽沿用本次窗口会话的收起偏好。回收站共用这套布局，设置页使用独立分类布局。

数字徽标悬停或获得键盘焦点时展开条件摘要，菜单打开时保持展开。菜单顶部为“回收站（数量）”和“清除筛选”，随后为类型和任务状态；详情见[任务状态与筛选](/#/docs/功能指南/任务状态与筛选)。设置与回收站期间不能通过该徽标修改正常列表筛选。

卡片标题、副标题从正文中提取前两条有效摘要，省略部分 Markdown 标记、空行及分隔内容；它们不是两个独立输入字段。过长内容以省略号显示，完整内容需载入编辑器或打开便签查看。列表内容较多时可滚动。

## 新建备忘录

1. 在编辑区输入内容，可直接使用 Markdown 或工具栏排版。
2. 点击保存图标或按 `Ctrl + Enter` 提交。
3. 新记录插入正常列表最上方，编辑区清空以继续新建；若不符合当前筛选，可通过“显示全部”查看，徽标只统计当前可见记录。

未提交的新建内容不会因为停输而自动成为一条记录。没有可提取有效内容时显示“内容不能为空”，例如只有空白或分隔线；开头有空行但后面有有效文字可以提交。普通新建每次创建一条记录，不使用剪贴板快速添加的内容去重规则。

## 编辑已有记录

1. **双击**卡片，将完整内容载入编辑器；当前编辑卡片会高亮。单击不会进入编辑。
2. 停止输入约 500ms 后自动保存，也可用保存按钮或 `Ctrl + Enter` 立即保存。
3. 立即保存后仍留在当前记录中。再次双击同一卡片会完成编辑并回到新建状态。
4. 双击另一张卡片会先保存当前编辑，再切换；点击工具栏“新建备忘录”也会先完成当前编辑。

进入已有记录前的未提交新建草稿会暂存在当前主窗口中，正常返回新建状态时可恢复；它不是跨重启草稿存储。

`Esc` 会恢复编辑器的恢复基准，并将恢复后的正文写回备忘录。初始基准是本次载入内容，手动立即保存成功后会更新基准；自动保存不更新基准。具体例子见[编辑器保存与恢复](/#/docs/功能指南/Markdown编辑器)。

## 排序、分离与删除

| 操作 | 结果 |
| --- | --- |
| 全部备忘、状态不限时，在列表内拖动并释放 | 调整卡片顺序并保存；筛选时仍可拖出便签。 |
| 将卡片拖出主窗口后释放 | 在释放位置附近打开[独立便签](/#/docs/功能指南/独立便签窗口)，原记录仍留在列表。 |
| 点击卡片右侧“删除” | 将记录移入回收站，保存成功后关闭对应便签并停止该记录的提醒；气泡提供即时“撤销”。 |

删除按钮随卡片悬停或键盘焦点等状态显现。任务卡片右侧状态按钮会为删除按钮让位，悬停状态按钮可查看当前状态名称，点击完成或重新打开任务。

从数字徽标菜单进入[回收站](/#/docs/功能指南/回收站)，可预览、恢复或彻底删除；普通删除无需确认，彻底删除和清空需要确认。编辑器的撤销只处理正文，找回卡片请使用删除气泡或回收站。

## 剪贴板快速添加

复制一段文字，在应用运行期间按 `Ctrl + Alt + C`，可直接加入备忘录，无需先切换到主窗口。默认还会在鼠标附近显示对应便签。

- 只处理非空剪贴板文本，文本首尾空白会去掉；复制图片请使用编辑器的图片粘贴。
- 若已有完全相同正文，通常复用该记录并提升到列表首位。
- 连续处理同一份未改变的剪贴板文本时，不再重复新增或反复提升；有对应记录时可再次显示其便签。
- 自动显示便签可以关闭，关闭后仍能添加文字；快速添加总功能关闭后该快捷键不起作用。

## 空白便签快速新建

按 `Ctrl + Alt + Q` 在鼠标位置打开草稿；重复触发会移动并激活同一个未保存草稿。首次保存后成为正式备忘录，后续编辑自动保存。关闭未保存草稿需在气泡中选择保存、不保存或取消；此快捷键独立于剪贴板快速添加开关。

## 窗口操作

拖动标题栏空白处移动窗口，拖动边缘或四角调整大小。默认尺寸为 420 × 680，最小为 360 × 480，均为逻辑尺寸，会随 Windows 缩放比例显示。

图钉切换主窗口置顶；最小化按钮隐藏主窗口并保留托盘运行。关闭按钮按已选的关闭行为处理，首次使用见[关闭行为确认气泡](/#/docs/功能指南/关闭行为对话框)。完整退出会停止本次运行中的提醒。

主窗口位置、尺寸、置顶和贴边状态会记忆。拖到工作区边缘可收起为[贴边方块](/#/docs/功能指南/主窗口贴边方块)。
