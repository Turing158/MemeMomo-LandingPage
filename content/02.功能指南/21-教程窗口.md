# 教程窗口

## 入口与用途

从主窗口进入“设置 → 关于与维护 → 教程”，打开内置教程。这是一份可滚动阅读的帮助窗口，方便在应用旁对照使用。

## 界面布局

标题栏显示教程标题、图钉和关闭按钮；下方是连续的使用说明，可滚动阅读。默认大小 380 × 360，最小 300 × 220 逻辑单位，不显示任务栏图标。

## 教程内容

| 部分 | 介绍内容 |
| --- | --- |
| Markdown 备忘录 | 单框编辑器、常用排版、提交与源码入口。 |
| 所见即所得编辑 | 双击卡片、自动保存、立即保存、恢复和格式快捷键。 |
| 插入图片 | 本地图片、拖入、粘贴与 HTTPS 图片。 |
| 分离便签 | 拖出卡片及重复便签偏好。 |
| 窗口调整 | 标题栏移动、边缘和四角缩放。 |
| 贴边停靠 | 主窗口收起方块及右键菜单。 |
| 置顶与关闭 | 图钉和主窗口关闭行为。 |
| 快捷键 | 显示本次打开时的六组实际快捷键（包含空白便签快速新建）。 |
| 托盘图标 | 单击 / 双击恢复以及右键菜单。 |
| 其他说明 | 常用偏好的即时应用和到期提醒方式。 |

内置教程是简要文字帮助，不是可在其中编辑的示例备忘录。具体功能的完整步骤以本目录对应页面为准。

## 操作和动态内容

拖动标题栏移动窗口，拖动边缘或四角缩放，点击图钉可置顶以便边看边操作。关闭只关闭此教程窗口，不退出应用。

最近激活的是教程时，全局置顶快捷键也可切换它。快捷键区域按打开时的配置生成，相关功能关闭时显示“已禁用”；修改配置后重新打开教程，可查看最新信息。语言切换会更新教程文案。

教程允许打开多个窗口，旧窗口中的快捷键配置不保证随之后的设置修改同步刷新。
