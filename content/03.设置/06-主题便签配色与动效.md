# 主题、便签配色与动效

## 主题颜色

位置：**设置 → 外观 → 主题颜色**。默认：**跟随系统**。

| 选项 | 效果 | 使用场景 |
| --- | --- | --- |
| 跟随系统 | 跟随 Windows 的应用明暗主题变化。 | 希望 MemeMomo 与系统保持一致。 |
| 亮色 | 固定使用亮色界面。 | 白天或偏好明亮界面。 |
| 暗色 | 固定使用暗色界面。 | 夜间或偏好深色界面。 |

点击对应选项即可切换，已打开的界面会更新。便签若选择了固定配色，其背景由“便签配色”决定。

## 便签配色

位置：**设置 → 外观 → 便签配色**。默认：**跟随主题**。

| 选项 | 背景效果 |
| --- | --- |
| 跟随主题 | 使用当前应用主题的背景。 |
| 炭黑（当前） | 炭黑色背景；括号是当前界面的选项名称，实际选中项以选择状态为准。 |
| 米白 | 偏暖的纸张色。 |
| 雾蓝 | 浅蓝色。 |
| 鼠尾草绿 | 浅灰绿色。 |
| 浅玫瑰 | 浅粉色。 |
| 淡紫 | 浅紫色。 |
| 暖沙 | 偏暖的浅沙色。 |

选择色块后，所有独立便签及其贴边标签会使用该配色，已打开的便签也会更新。标题栏与正文背景保持同色，边框、文字和编辑器中的相关颜色自动搭配。

这是便签窗口的统一配色，不是每条备忘录分别选择颜色的功能。主窗口及其设置页继续使用“主题颜色”。选择“跟随主题”即可恢复便签与应用主题一致的背景。

## 界面动效

位置：**设置 → 外观 → 界面动效**。默认：**跟随系统**。

| 选项 | 效果 |
| --- | --- |
| 跟随系统 | 根据 Windows 的动画偏好启用或减少动画，并显示“系统当前已开启动画”或“系统当前已减少动画”。 |
| 始终开启 | 不受系统减少动画偏好影响，保持应用内动画。 |
| 关闭动画 | 关闭窗口过渡、控件微交互等动画，直接呈现操作结果。 |

点击即可生效。关闭动画不会关闭贴边、提醒或设置功能；页面切换、列表收起、筛选徽标展开及任务按钮变化会直接到达最终状态，检测更新等操作仍会执行。
