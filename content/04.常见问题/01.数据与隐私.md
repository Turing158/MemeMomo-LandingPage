# 数据与隐私

适用版本：`v1.0.0`

## 数据在哪

全部数据都在本机，**不会上传到任何服务器**：

| 内容 | 位置 |
| --- | --- |
| 备忘录、任务信息、提醒与回收站记录 | `%AppData%/MemeMomo/memos.json` |
| 任务状态（内置与自定义） | `%AppData%/MemeMomo/task-statuses.json` |
| 软件偏好与自动记忆的窗口状态 | `%AppData%/MemeMomo/settings.json` |
| 插入的本地图片 | `%AppData%/MemeMomo/assets/` |

退出应用不会丢失数据；重新打开会原样恢复。

## 迁移

换电脑时把整个 `%AppData%/MemeMomo/` 目录拷贝到新机器的相同位置即可完成迁移，不需要导出导入。

## 备份

备份前先完全退出应用，再复制整个 `%AppData%/MemeMomo/` 文件夹。目录里的 `.bak`、`.pre-tasks.bak`、`.pre-recycle-bin.bak` 等文件是日常保存和升级前自动生成的副本，可用于版本回退；回退旧版应使用升级前的配套数据。数据是纯文件（Markdown 文本 + 配置），任何文件级备份方案（手动复制、网盘同步、版本管理）都适用。详见 [设置保存与自动记忆的状态](/#/docs/设置/设置保存与自动记忆的状态)。
