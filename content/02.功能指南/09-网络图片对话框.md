# 网络图片对话框

## 入口与布局

在 Markdown 工具栏或“更多格式”中选择“网络图片”。面板提供图片地址输入框、清空地址按钮、帮助说明、插入和取消按钮，以及右上角关闭入口。

## 插入图片

1. 输入完整的 HTTPS 图片地址，例如 `https://example.com/photo.png`。
2. 点击插入按钮，或在输入框中按 `Enter`。
3. 地址通过校验后，面板关闭，在正文插入网络图片引用。

默认替代文字为“网络图片”。如需更改替代文字或地址，右键图片选择[编辑图片](/#/docs/功能指南/图片编辑对话框)，也可打开[源码对话框](/#/docs/功能指南/Markdown源码对话框)。

## 校验与取消

| 操作或状态 | 结果 |
| --- | --- |
| 输入为空 | 插入按钮不可用。 |
| 输入 HTTP、本地路径或无效地址并提交 | 通过气泡提示校验错误，保留面板供修改。 |
| 输入有效 HTTPS 地址 | 可以提交，但此时只确认地址格式。 |
| 点击地址清空按钮 | 清空输入，继续停留在面板。 |
| 点击取消、右上角关闭或按 `Esc` | 放弃本次插入，回到原编辑位置。 |

本对话框没有图片预览，也不会在确认前证明地址确实返回一张可显示的图片。

## 图片如何加载

返回编辑器后，图片进入可见区域时会加载；网络失败、资源不存在、超过大小限制或格式不能解码，都可能导致图片无法呈现。单张内容限制为 20 MiB，网络请求可能等待到超时。

网络图片保存的是 HTTPS 引用，**不会作为本地插图自动复制进 `assets`**。断网或原站删除图片后，已保存的引用仍在，但不保证能够显示。需要离线保留时，应先自行保存图片，再通过本地图片入口插入。

加载成功后的尺寸调整见[图片宽度工具栏](/#/docs/功能指南/图片宽度浮动工具栏)。插入动作遵循当前备忘录的保存规则。
