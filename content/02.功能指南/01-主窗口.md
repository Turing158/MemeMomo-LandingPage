# 主窗口


## 用途与打开方式

主窗口是备忘录的管理入口，负责创建记录、编辑正文、浏览摘要、删除和调整顺序。启动应用后显示主窗口或上次保存的贴边状态；也可通过托盘菜单的“打开备忘录”、托盘图标默认双击或 `Ctrl + Alt + N` 找回。

重复启动程序会尝试唤起已经运行的实例。主窗口默认不显示任务栏图标，因此任务栏没有按钮不代表应用已经退出。

## 界面布局

| 区域 | 内容与作用 |
| --- | --- |
| 标题栏左侧 | 产品图标、MemeMomo 名称、备忘录数量；数量为零时不显示计数徽章。 |
| 标题栏右侧 | 设置、置顶、最小化、关闭。设置面板见已有设置文档。 |
| 顶部编辑区 | [Markdown 编辑器](/#/docs/功能指南/Markdown编辑器)，用于新建或编辑当前备忘录。 |
| 下方列表 | 每张卡片包含标题、可用时的副标题、创建时间，以及删除按钮。 |
| 空列表 | 显示“还没有备忘录”和在上方输入后按 `Ctrl+Enter` 的引导。 |

卡片标题、副标题从正文中提取前两条有效摘要，省略部分 Markdown 标记、空行及分隔内容；它们不是两个独立输入字段。过长内容以省略号显示，完整内容需载入编辑器或打开便签查看。列表内容较多时可滚动。

## 新建备忘录

1. 在顶部输入内容，可直接使用 Markdown 或工具栏排版。
2. 点击保存图标或按 `Ctrl + Enter` 提交。
3. 新记录插入列表最上方，计数增加，编辑区清空以继续新建。

未提交的新建内容不会因为停输而自动成为一条记录。没有可提取有效内容时显示“内容不能为空”，例如只有空白或分隔线；开头有空行但后面有有效文字可以提交。普通新建每次创建一条记录，不使用剪贴板快速添加的内容去重规则。

## 编辑已有记录

1. **双击**卡片，将完整内容载入顶部编辑器；当前编辑卡片会高亮。单击不会进入编辑。
2. 停止输入约 500ms 后自动保存，也可用保存按钮或 `Ctrl + Enter` 立即保存。
3. 立即保存后仍留在当前记录中。再次双击同一卡片会完成编辑并回到新建状态。
4. 双击另一张卡片会先保存当前编辑，再切换；点击工具栏“新建备忘录”也会先完成当前编辑。

进入已有记录前的未提交新建草稿会暂存在当前主窗口中，正常返回新建状态时可恢复；它不是跨重启草稿存储。

`Esc` 会恢复编辑器的恢复基准，并将恢复后的正文写回备忘录。初始基准是本次载入内容，手动立即保存成功后会更新基准；自动保存不更新基准。具体例子见[编辑器保存与恢复](/#/docs/功能指南/Markdown编辑器)。

## 排序、分离与删除

| 操作 | 结果 |
| --- | --- |
| 按住卡片，在列表内上下拖动并释放 | 调整卡片顺序并保存；拖动时会显示位置变化，靠近列表边缘可触发滚动。 |
| 将卡片拖出主窗口后释放 | 在释放位置附近打开[独立便签](/#/docs/功能指南/独立便签窗口)，原记录仍留在列表。 |
| 点击卡片右侧“删除” | 直接删除记录并保存，无额外删除确认；对应的便签窗口和提醒窗口会关闭。 |

删除按钮随卡片悬停、编辑等状态显现。当前没有回收站或恢复已删除卡片的按钮；编辑器的撤销不能撤销列表删除。

## 剪贴板快速添加

复制一段文字，在应用运行期间按 `Ctrl + Alt + C`，可直接加入备忘录，无需先切换到主窗口。默认还会在鼠标附近显示对应便签。

- 只处理非空剪贴板文本，文本首尾空白会去掉；复制图片请使用编辑器的图片粘贴。
- 若已有完全相同正文，通常复用该记录并提升到列表首位。
- 连续处理同一份未改变的剪贴板文本时，不再重复新增或反复提升；有对应记录时可再次显示其便签。
- 自动显示便签可以关闭，关闭后仍能添加文字；快速添加总功能关闭后该快捷键不起作用。

## 窗口操作

拖动标题栏空白处移动窗口，拖动边缘或四角调整大小。默认尺寸为 420 × 680，最小为 360 × 480，均为逻辑尺寸，会随 Windows 缩放比例显示。

图钉切换主窗口置顶；最小化按钮隐藏主窗口并保留托盘运行。关闭按钮按已选的关闭行为处理，首次使用见[关闭行为对话框](/#/docs/功能指南/关闭行为对话框)。完整退出会停止本次运行中的提醒。

主窗口位置、尺寸、置顶和贴边状态会记忆。拖到工作区边缘可收起为[贴边方块](/#/docs/功能指南/主窗口贴边方块)。
