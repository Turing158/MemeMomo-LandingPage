# 操作反馈与确认气泡

## 所在位置与用途

保存、复制、图片导入、快捷键校验、检测更新、任务状态和提醒操作，在发起操作的窗口内使用统一气泡。设置及管理状态使用主窗口的气泡层，提醒页使用当前便签，链接或图片编辑校验使用相应对话框。

普通信息、成功、错误用不同状态呈现；同一操作的进度和结果更新同一条消息。普通消息会在一段时间后消失，悬停或键盘焦点进入消息区可展开消息列表并暂停计时。一般反馈不会抢走输入焦点。

Windows 到期系统通知仍由系统显示，见[系统提醒通知](/#/docs/功能指南/Windows系统提醒通知)。

## 需要选择的气泡

| 场景 | 选择与作用 |
| --- | --- |
| 删除表格 | 确定删除整个表格，取消保留；触发点是紧接表格的末尾空行上的边界删除。 |
| 彻底删除或清空回收站 | 显示记录名称或清空数量，确定后移除记录。 |
| 重置设置 | 确定后恢复普通偏好。 |
| 任务状态迁移 | 显示影响任务和提醒数量，确认后提交迁移。 |
| 关闭未保存的快速便签 | 保存后关闭、不保存并关闭，或取消关闭。 |
| 首次关闭主窗口 | 选择最小化托盘、关闭应用或取消。 |

确认气泡持续等待选择，不会因超时自动执行。普通列表删除直接移入回收站并显示“撤销”，不需要事前确认。引用块、代码块和图片的右键直接删除属于正文编辑，可用编辑器撤销恢复。

## 键盘与取消

- 初始焦点在第一项，现有确认场景第一项为“取消”。
- `Tab` / `Shift + Tab` 在选项间循环；`Enter` / `Space` 执行当前聚焦选项。
- `Esc` 取消；隐藏或关闭所属窗口同样取消未确认操作。
- 确认完成后恢复合理的原焦点，不能重复点击旧气泡执行新操作。

确认气泡没有独立窗口标题栏，不能单独拖动。保存失败等错误气泡只反馈结果；它消失并不表示数据已经保存，应处理原因后重试。
