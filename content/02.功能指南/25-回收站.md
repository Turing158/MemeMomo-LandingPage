# 回收站

## 删除与进入

正常列表卡片上的删除按钮会把记录移入回收站；保存成功后关闭该记录的所有便签并停止提醒，同时显示带“撤销”的气泡。删除前会收集正在编辑的最新正文；保存失败时保留原记录供重试。

点击标题栏数字徽标，选择菜单首项“回收站（数量）”。回收站默认长期保留记录，不按天自动清理。

## 预览与布局

单击卡片选择记录，上下布局在上方预览，左右布局在右侧预览。预览保留 Markdown、表格、图片及代码显示，可滚动、选取、全选、复制或复制代码。工具栏隐藏，不能输入、勾选正文任务项、改状态、改表格、调整图片、重排或拖出便签。

记录按删除时间从近到远排列。卡片左侧为恢复，右侧为彻底删除；用方向键、`Enter` 或 `Space` 也可选择预览。处理选中记录后，选择移到相邻记录；空列表时显示空状态。

左右布局下可通过标题栏应用图标收起列表，以扩大预览。再次点击展开列表后可使用返回和清空入口。

## 恢复、彻底删除与清空

| 操作 | 结果 |
| --- | --- |
| 删除气泡中的“撤销” | 恢复刚移入回收站的记录。气泡消失后仍可从回收站恢复。 |
| 卡片左侧“恢复” | 保留原 ID、正文、创建时间和任务信息，放回正常列表顶部，不按正文去重。 |
| 卡片右侧“彻底删除” | 确认后从数据记录中移除，无法从回收站恢复。 |
| 工具行右侧警示垃圾桶 | 悬停展开“全部清空”；点击显示数量确认，仅删除本次确认范围内的回收站记录。 |

回收站为空或操作处理中不能清空。取消、`Esc` 或关闭未完成的确认不会执行删除；写入失败保留记录并显示错误。恢复后若记录不符合正常列表筛选，会提示被筛选隐藏，可返回后清除筛选。

恢复不会自动重新打开原便签窗口。彻底删除记录不等同于清理 `assets` 中的图片文件，也不删除已有备份副本。

## 提醒与任务

- 删除期间不触发提醒，并取消应用内可追踪的排队通知；系统历史通知不保证撤回。
- 恢复时保留仍在未来且允许触发的提醒；过期提醒会清除并提示重新设置，已结束任务也不会恢复提醒。
- 状态引用仍保留；若对应自定义状态已经不存在，显示“状态已缺失”，恢复后可选择有效状态。
- 回收站记录不参与正常任务使用数和状态迁移。

## 返回原工作区

点击回收站工具行返回箭头，恢复进入前的草稿或编辑记录、类型选择、筛选及浏览位置。进入前已有记录保存失败时会留在原页面；原记录被其他操作删除后，返回时恢复新建草稿。

回收站与设置可以往返，设置返回后仍回到原回收站预览。页面保留只在当前运行中有效，新建草稿仍需主动保存。

## 数据与源码

回收站与正常记录一起存放在 `memos.json`，`deletedAt` 记录 UTC 删除时间，没有单独的回收站文件。完整备份需同时保留状态目录、设置、图片和备份文件；旧版不理解删除字段，回退应恢复升级前数据，详见[数据保存与备份](/#/docs/设置/设置保存与自动记忆的状态)。
