# 日期选择浮层


## 入口与用途

在[提醒设置窗口](/#/docs/功能指南/提醒设置窗口)点击日期字段，打开浮动日历。当前日期字段是选择控件，**不能直接输入日期文字**。需要跳到远期日期时，可通过月份和年份层级快速定位。

## 三个层级

| 层级 | 中间区域 | 标题按钮与左右箭头 |
| --- | --- | --- |
| 日期 | 星期表头与日期网格，包含相邻月份的日期。 | 点击标题进入月份选择；左右箭头翻月。 |
| 月份 | 一年的月份选项。 | 点击标题进入年份选择；左右箭头翻年。 |
| 年份 | 当前十年及相邻年份选项。 | 左右箭头按十年翻页；点击标题可返回月份层级。 |

当天、当前选中日期、非当前月份的日期以不同状态显示，便于区分“今天”和“正在选择哪一天”。底部“今天”始终用于快速选回当天。

## 鼠标操作

1. 打开日期字段，按需翻月。
2. 要跨较远年份，点击标题切到月份，再点击切到年份。
3. 选择年份后回到月份，选择月份后回到日期。
4. 点击具体日期，或点击“今天”，将日期写入提醒面板并收起浮层。

只切换年份、月份或浏览日期不会提交一条提醒。最终选中日期之后，仍需回到提醒窗口点击“设置提醒”。选择过去日期也不代表能安排过去提醒，提交时还要检查完整日期和时间。

## 键盘操作

| 焦点位置 / 按键 | 作用 |
| --- | --- |
| 日期字段中按 `Enter` / `Space` | 打开或收起日历。 |
| 日期网格中 `←` / `→` | 焦点移到前一天 / 后一天。 |
| 日期网格中 `↑` / `↓` | 焦点移到前一周 / 后一周。 |
| `PageUp` / `PageDown` | 日期层翻月、月份层翻年、年份层翻十年。 |
| 日期层 `Home` / `End` | 焦点移到月初 / 月末。 |
| 月份或年份层方向键 | 在当前选项网格中移动焦点。 |
| `Enter` / `Space` | 选择当前焦点项；年月项进入下一层，日期项确认日期。 |
| `Esc` | 收起浮层并返回日期字段，不取消原有提醒。 |

点击浮层外部也可收起。仅浏览、移动焦点后关闭不会把浏览日期当作已选日期。
