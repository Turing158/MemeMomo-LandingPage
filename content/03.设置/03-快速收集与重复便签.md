# 快速收集与重复便签

| 设置 | 界面位置 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 快速添加剪贴板内容 | 设置 → 通用 | 开启 | 使用全局快捷键把剪贴板中的文本保存为备忘录。 |
| 快速添加后自动显示便签 | 设置 → 通用 | 开启 | 快速添加成功后，在鼠标附近显示对应便签窗口。依赖“快速添加剪贴板内容”。 |
| 重复便签 | 设置 → 窗口与便签 | 关闭 | 控制从列表再次拖出同一条备忘录时，复用已有窗口还是再创建一个窗口。 |

## 空白便签快速添加

按 `Ctrl + Alt + Q` 打开一个空白便签，可在「设置 → 快捷键 → 快速添加」修改或清空组合。这个入口独立于剪贴板快速添加开关。

输入内容后点击保存或按 `Ctrl + Enter`，才会新增备忘录。首次保存前不会因停输而自动新增；再次触发快捷键会把同一个未保存窗口移到鼠标处，并保留草稿。首次保存后，此窗口转为普通独立便签，后续编辑沿用自动保存，再次触发快捷键可开始下一条记录。

首次保存前关闭窗口会通过气泡询问「保存／不保存／取消」。选择保存会新增后关闭；不保存会丢弃草稿；取消则继续编辑。空内容或保存失败时保留窗口。退出应用时也会先处理此草稿。该确认仅针对快速添加的未保存便签。

## 剪贴板快速添加的用法

1. 在任意应用中复制一段文本。
2. 按默认快捷键 `Ctrl + Alt + C`，或使用自己设置的“快速添加（剪贴板）”快捷键。
3. MemeMomo 收集该文本；若开启自动显示便签，会在鼠标附近显示便签。关闭自动显示时，可以稍后回到主窗口查看。

快速添加读取的是剪贴板文本。空白文本、仅含图片或文件而不含文本的剪贴板不会通过此功能新建备忘录；图片可通过编辑器的粘贴、拖入或插入功能处理。

正常列表已有相同正文时会复用那条备忘录，处理新的剪贴板文本时可将已有条目移到列表前面。连续触发同一段剪贴板文本不会不断创建相同内容的条目。回收站记录不参与正常快速添加去重，收集同样文字不会自动恢复已删除记录。真正创建新记录时采用“任务与提醒”中的默认类型和状态。

关闭“快速添加剪贴板内容”后，“快速添加后自动显示便签”会折叠，剪贴板快速添加快捷键按钮会禁用，该全局快捷键也不再注册。自动显示选项和快捷键的原值会保留，重新开启后可继续使用。

## 重复便签的用法

从主窗口列表按住一张备忘录卡片并拖出，即可打开独立便签。

- **关闭重复便签**：若该备忘录已有窗口，通常会移动并激活已有窗口；若窗口正处于贴边状态，普通拖出入口会保留其贴边位置。
- **开启重复便签**：再次从列表拖出同一条备忘录时，可以创建另一个窗口，用于在不同位置查看同一内容。

这里的“重复”指同一条备忘录的多个窗口，不会复制成多条独立数据。快速添加的文本去重不受此开关影响；快速添加自动显示便签时也会优先复用已有窗口。
