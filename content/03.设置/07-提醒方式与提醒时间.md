# 提醒方式与提醒时间

## 全局提醒方式

位置：**设置 → 任务与提醒 → 提醒方式**。默认：**系统通知**。

| 选项 | 到期时的行为 |
| --- | --- |
| 系统通知 | 发送 Windows 通知；及时点击当前通知，可显示对应便签。 |
| 应用内窗口 | 打开或复用对应便签；新窗口按主窗口所在工作区居中。 |
| 两者 | 同时显示便签窗口并发送系统通知。点击当前通知时优先复用对应窗口。 |

切换后，后续到期提醒按新选择处理，无需重启；已经发出的通知不会被重新投递。多条同时到期的系统通知会按提醒时间依次发送，不会合成一条汇总通知。

到期显示便签时会优先复用已有窗口，已有便签若已贴边，应用内提醒可能保持其标签状态，需要拖出查看。点击当前有效的系统通知则会让对应贴边便签恢复为完整窗口。

系统通知受 Windows 的通知权限、免打扰和通知声音设置控制。应用内没有单独的提醒音量、铃声、通知时长或“关闭所有提醒”选项。免打扰导致通知不显示时，不会自动改成应用内弹窗；需要直接弹窗可选择“应用内窗口”或“两者”。

当前通知实现对历史通知的定位有限：从通知中心点击较早的条目，可能只恢复主窗口，也可能不收到系统点击回调；查看旧提醒时可直接打开主窗口。短时间积压过多通知、等待队列超过 32 条时，“系统通知”模式下超出的提醒会改用应用内窗口。

## 为一条备忘录设置时间

1. 从列表拖出需要提醒的便签，点击标题栏的时钟“设置提醒”，在同一个便签内进入提醒页。
2. 选择日期，再通过时、分、秒滚轮设置时间；也可直接点击“1分钟后”“10分钟后”“半小时后”“1小时后”。快捷时间以点击时的当前时间计算，并同步更新日期。
3. 点击“设置提醒”保存。时间必须晚于当前时间，过近或已经过去的时间会显示错误提示。

尚未设置未来提醒时，面板默认预选约 **10 分钟后**，必须点击“设置提醒”才会保存。已有未来提醒时，重新进入提醒页会显示已保存的提醒时间，修改后再次点击“设置提醒”即可替换。

点击“设置提醒”或“取消提醒”成功后返回正文。再次点击时钟、点击“取消”或在没有日历浮层时按 `Esc`，会放弃本次调整并保留已有提醒；右上角关闭按钮关闭整个便签。时钟高亮表示当前正在提醒页，小圆点表示已保存未来提醒。

这里的时间选择需要提交，与普通设置偏好的自动保存不同。详细操作见[提醒设置页](/#/docs/功能指南/提醒设置窗口)。

提醒属于单条备忘录，是一次性的，到期处理后会清除已安排的时间。应用驻留托盘时仍会检查提醒；完全退出后不再运行。下次启动加载数据时，会处理尚未触发且已经到期的提醒。

删除到回收站后不再提醒。恢复时保留未来提醒，已过期的提醒清除并提示重新设置；回收站中的过期记录不会在启动时补发提醒。

## 任务提醒限制

暂缓任务保留提醒。完成或取消任务会清除提醒并取消应用内通知队列记录；重新打开后需重新设置提醒。详见[任务与状态](/#/docs/设置/任务与状态)。
