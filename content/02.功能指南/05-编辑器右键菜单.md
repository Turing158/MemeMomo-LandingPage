# 编辑器右键菜单


## 入口

在主窗口或独立便签的正文编辑区域右键。此菜单处理正文剪贴板操作；表格单元格中的右键菜单另外包含行列命令，见[表格编辑与右键菜单](/#/docs/功能指南/表格编辑与右键菜单)。

## 菜单项

| 条目 | 作用 |
| --- | --- |
| 剪切 | 将选中的正文复制到剪贴板并从当前正文移除；没有可剪切选区时不可执行。 |
| 复制 | 复制所选正文，不改变内容。需要完整 Markdown 标记时，可到源码对话框复制。 |
| 粘贴 | 在当前位置插入或替换选区；普通文字走文本粘贴，图片或图片文件走图片插入。 |

粘贴项仅在检测到可用文本或图片数据时显示；剪贴板为空时可能看不到该项。文件列表中的图片仍需通过格式、存在性及大小检查。

对应快捷键为 `Ctrl + X`、`Ctrl + C`、`Ctrl + V`。剪切和粘贴会改变正文，遵循[编辑器保存规则](/#/docs/功能指南/Markdown编辑器)；复制不触发内容修改。

图片文件列表不是整篇 Markdown 文件导入，普通文件也不会作为附件存入备忘录。
