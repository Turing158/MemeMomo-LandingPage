# 写下第一条备忘录

适用版本：`v0.0.1`

## 新增

在主窗口顶部的编辑器中输入内容，按 `Ctrl + Enter` 立即新增一条备忘录。两个细节：

- 首行为空的内容不会被提交。
- 在编辑已有备忘录时按 `Ctrl + Enter`，效果是立即保存并保持当前编辑状态。

## 自动保存

编辑停止约 **500ms** 后内容会自动保存；按 `Esc` 可以恢复本次载入时的内容。不需要手动点保存按钮。

## 编辑已有备忘录

点击列表中的任意卡片即可载入编辑。编辑器支持 Markdown 语法，详见 [Markdown 编辑器](/#/docs/功能指南/Markdown编辑器)。

## 删除

把鼠标悬停在卡片上，右侧会出现删除按钮；删除会弹确认对话框，防止误触。

## 快速添加剪贴板

想让一段复制来的文字立刻变成备忘录？按下全局快捷键 `Ctrl + Alt + C`，剪贴板中的文本会直接新增为一条备忘录。这个开关可以在「设置 → 快捷键设置」中关闭或改绑。
