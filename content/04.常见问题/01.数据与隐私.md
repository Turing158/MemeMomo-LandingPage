# 数据与隐私

适用版本：`v0.0.1`

## 数据在哪

全部数据都在本机，**不会上传到任何服务器**：

| 内容 | 位置 |
| --- | --- |
| 备忘录 | `%AppData%/MemeMomo/` |
| 设置 | `%AppData%/MemeMomo/` |
| 图片 | `%AppData%/MemeMomo/` |

退出应用不会丢失数据；重新打开会原样恢复。

## 迁移

换电脑时把整个 `%AppData%/MemeMomo/` 目录拷贝到新机器的相同位置即可完成迁移，不需要导出导入。

## 备份

数据是纯文件（Markdown 文本 + 配置），任何文件级备份方案（手动复制、网盘同步、版本管理）都适用。
