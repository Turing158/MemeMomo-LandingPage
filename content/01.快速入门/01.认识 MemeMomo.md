# 认识 MemeMomo

适用版本：`v1.0.0`

MemeMomo 是一款专注于快速记录和持续查看的 Windows 桌面备忘录。它不是复杂的知识库，也不会把你的内容上传到云端：打开应用，写下一段 Markdown，之后让它安静地停在桌面边缘，或者变成一张独立便签。

你可以把它当成：**一个随时在手边的 Markdown 草稿本 + 一组可独立摆放的桌面便签 + 一份轻量的任务清单**。

## 它适合做什么

- **随手记**：灵感、待办、购物清单、会议纪要，`Ctrl + Enter` 一键提交。
- **推进任务**：备忘录可以标记为任务，用待办、进行中、暂缓、已完成、已取消跟踪进度，状态的名称、颜色与图标都能自定义。
- **贴在桌面上**：主窗口可以吸附屏幕边缘收起成小方块，随时唤出。
- **独立便签**：把一条备忘录钉在工作区角落，配合置顶使用。
- **重要事项提醒**：精确到秒的定时提醒，应用在托盘驻留时也会触发。
- **删错也不怕**：删除的记录先进入回收站，可以预览、恢复或彻底清除。

## 界面总览

主窗口是一个紧凑的无边框圆角窗口：

| 区域 | 说明 |
| --- | --- |
| 标题栏 | 应用图标、名称与数量徽标；右侧依次是设置、置顶、最小化、关闭。徽标显示当前可见条数，点击打开类型/状态筛选与回收站菜单 |
| 编辑器 | Markdown 编辑区，所见即所得，带格式工具栏，最左侧可选择普通备忘或任务 |
| 备忘录列表 | 按时间排列的卡片；清除筛选后可拖拽重排，可拖出窗口变成独立便签，任务卡片右侧有状态按钮 |

窗口较窄时编辑器在上、列表在下；宽度达到 660 DIP 后列表在左、编辑器在右，此时点击标题栏应用图标可收起或展开列表。

## 技术形态

MemeMomo 使用 **.NET 8 + WPF（C#）** 构建，面向 Windows 10/11。它不依赖任何后台服务，全部数据保存在本机 `%AppData%/MemeMomo/` 目录下。安装与启动方式见 [安装与启动](/#/docs/快速入门/安装与启动)。
