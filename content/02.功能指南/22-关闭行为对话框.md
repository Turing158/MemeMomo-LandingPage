# 关闭行为确认气泡

## 何时出现

主窗口尚未记录关闭按钮行为时，点击标题栏关闭按钮，在主窗口内显示确认气泡。气泡直接提供三个按钮：

| 选择 | 结果 |
| --- | --- |
| 取消 | 保留主窗口，不记录关闭选择。 |
| 最小化托盘 | 记住该选择，本次隐藏主窗口，应用和提醒继续运行。 |
| 关闭 | 记住该选择，进入完整退出流程。 |

直接点击相应按钮即可选择，无需先切换分段选项再点“确认”。以后关闭沿用所选行为，也可在“设置 → 通用 → 关闭按钮操作”中修改；重置偏好会恢复首次询问。

## 键盘与取消

初始焦点在“取消”。用 `Tab` / `Shift + Tab` 切换按钮，`Enter` 或 `Space` 执行当前聚焦的选项；`Esc` 取消。隐藏或关闭宿主会取消尚未完成的询问。

独立便签不使用这组应用关闭选项：已保存便签只关闭窗口；尚未保存的快速新建便签使用保存、不保存、取消气泡。完整退出始终可从托盘菜单进入。

更多通用规则见[操作反馈与确认气泡](/#/docs/功能指南/确认提示对话框)。
