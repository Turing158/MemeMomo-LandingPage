# 表格编辑与右键菜单


## 入口与布局

通过[表格插入面板](/#/docs/功能指南/表格插入面板)创建，或在正文中粘贴受支持的 Markdown 表格。表格直接显示在编辑区内，第一行为表头，每个可见单元格都能点击输入。列宽会随内容及编辑器宽度调整，长文本可在单元格中视觉换行。

## 单元格输入

| 操作 | 实际效果 |
| --- | --- |
| 点击单元格 | 聚焦该格并编辑文字。 |
| `Tab` / `Shift + Tab` | 按行顺序移向下一个 / 上一个现有单元格；到首尾不会自动新增行。 |
| 方向键 | 优先移动格内光标，到内容边缘后可移到相邻单元格或表格外。 |
| `Enter` | 单元格可接收换行，但保存到 Markdown 时换行会归一为空格；不创建新表格行。 |
| `Ctrl + Enter` | 请求保存当前备忘录。 |
| `Esc` | 恢复当前备忘录的编辑基准，影响范围不只当前单元格。 |

单元格主要作为文本编辑区域。粘贴多行内容后，持久化文本会合并换行并去掉首尾空白；不要依赖格内换行来保存多段结构。

## 右键菜单

在需要操作的单元格右键：

| 条目 | 作用 |
| --- | --- |
| 剪切 / 复制 | 有选区时作用于所选文字；**没有选区时作用于整个单元格文本**。剪切会清空对应内容。 |
| 粘贴 | 粘贴剪贴板文字；没有文本时隐藏。单元格菜单不提供正文的图片粘贴分支。 |
| 上方插入行 / 下方插入行 | 在当前行附近增加空行，并保持 Markdown 表头结构。 |
| 删除行 | 删除当前可删除的行；删除表头时，若有正文行，会将首个正文行提升为表头。 |
| 左侧插入列 / 右侧插入列 | 在当前列附近增加一列，作用于整个表格。 |
| 删除列 | 删除当前列，作用于整个表格。 |

命令作用于右键所对应的单元格位置，行列操作立即改变当前正文，没有额外“应用”按钮。

## 删除整表与当前限制

光标位于紧接表格的末尾空行时，按 `Backspace` 或 `Delete` 可能打开[删除表格确认](/#/docs/功能指南/确认提示对话框)。确认会删除整个表格；取消保留它。也可在源码对话框中明确删除表格 Markdown 后应用。

- 删除行有结构保护：只剩表头，或尝试删除最后一个正文行时，操作可能保持不变。
- 当前实现对**仅剩一列时的“删除列”存在异常分支，会插入空列而非移除整表**。需要删整表时使用上述确认入口或源码编辑。
- 表格不提供电子表格公式、排序、合并单元格或批量数据导入界面。

表格修改遵循[编辑器保存与恢复规则](/#/docs/功能指南/Markdown编辑器)。
